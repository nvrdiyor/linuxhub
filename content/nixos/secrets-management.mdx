NixOS configuration — Git'da. Lekin **secrets** (parol, API key, sertifikat) Git'da plain text bo'lishi mumkin emas. **sops-nix** va **agenix** — Nix uchun encryption tools.[¹](https://github.com/Mic92/sops-nix)

<Callout type="info" title="Bu darsda nimani o'rganasiz">
- Nix store'da secrets — nima uchun xavfli.
- sops-nix — Mozilla SOPS + Nix.
- agenix — age encryption + Nix.
- Age yoki SSH key bilan.
- Secret'lar systemd service'larga.
</Callout>

## 1. Muammo

NixOS config:

```nix
{
  services.postgresql = {
    enable = true;
    initialScript = pkgs.writeText "init.sql" ''
      CREATE USER admin WITH PASSWORD 'MySecret!';     -- CLEAR TEXT — XAVFLI
    '';
  };
}
```

Bu — Nix store'ga clear text borib qoladi. Hamma o'qiy oladi.

## 2. sops-nix yondashuvi

SOPS (Secrets OPerationS) — Mozilla loyihasi. YAML/JSON faylni qisman encrypt qiladi.

```yaml
# secrets/example.yaml
db_password: ENC[AES256_GCM,data:abc123...,tag:xyz...]
api_key: ENC[AES256_GCM,data:def456...,tag:uvw...]
```

Faqat qiymatlar encrypt'lanadi — kalit'lar plain (diff'ga ko'rinadi).

## 3. age key

Age — modern encryption (SSH alternative):

```bash
# Lokal mashinada
nix-shell -p age
age-keygen -o ~/.config/sops/age/keys.txt
cat ~/.config/sops/age/keys.txt
# # created: 2026-05-26T14:00:00+05:00
# # public key: age1abc123...
# AGE-SECRET-KEY-1XYZ...
```

Public key — config'da, private key — `~/.config/sops/age/`.

## 4. SOPS config

`.sops.yaml` (project root):

```yaml
keys:
  - &laptop age1abc123...     # sizning public key
  - &server age1def456...     # server public key
creation_rules:
  - path_regex: secrets/.+\.yaml$
    key_groups:
      - age:
        - *laptop
        - *server
```

## 5. Secret yaratish

```bash
sops secrets/example.yaml
```

Editor ochiladi — plain YAML kiriting:

```yaml
db_password: MySecretPass!
api_key: sk-1234567890
```

Saqlab chiqishganda — avtomatik encrypt:

```yaml
db_password: ENC[AES256_GCM,data:...,...]
api_key: ENC[AES256_GCM,data:...,...]
sops:
  age:
    - recipient: age1abc123...
      enc: |
        -----BEGIN AGE ENCRYPTED FILE-----
        ...
        -----END AGE ENCRYPTED FILE-----
```

## 6. sops-nix module

`flake.nix`:

```nix
{
  inputs = {
    nixpkgs.url = "github:NixOS/nixpkgs/nixos-24.05";
    sops-nix = {
      url = "github:Mic92/sops-nix";
      inputs.nixpkgs.follows = "nixpkgs";
    };
  };

  outputs = { self, nixpkgs, sops-nix, ... }: {
    nixosConfigurations.myserver = nixpkgs.lib.nixosSystem {
      system = "x86_64-linux";
      modules = [
        ./configuration.nix
        sops-nix.nixosModules.sops
      ];
    };
  };
}
```

## 7. configuration.nix

```nix
{ config, pkgs, ... }:
{
  sops.defaultSopsFile = ./secrets/example.yaml;
  sops.age.keyFile = "/var/lib/sops-nix/key.txt";

  sops.secrets.db_password = {
    owner = "postgres";
    group = "postgres";
    mode = "0400";
  };

  sops.secrets.api_key = {
    owner = "myapp";
  };

  services.postgresql = {
    enable = true;
    initialScript = pkgs.writeText "init.sql" ''
      CREATE USER admin WITH PASSWORD ' '@PASSWORD@' ';
    '';
  };

  systemd.services.myapp = {
    serviceConfig = {
      EnvironmentFile = config.sops.secrets.api_key.path;
    };
  };
}
```

`config.sops.secrets.<name>.path` — `/run/secrets/<name>` (tmpfs).

## 8. agenix alternativi

Yengilroq, faqat age:

```nix
{
  inputs.agenix.url = "github:ryantm/agenix";

  outputs = { self, nixpkgs, agenix, ... }: {
    nixosConfigurations.myserver = nixpkgs.lib.nixosSystem {
      modules = [
        agenix.nixosModules.default
        ./configuration.nix
      ];
    };
  };
}
```

`secrets.nix`:

```nix
let
  laptop = "age1abc...";
  server = "age1def...";
in
{
  "secrets/db_password.age".publicKeys = [ laptop server ];
  "secrets/api_key.age".publicKeys = [ laptop server ];
}
```

Encrypt:

```bash
agenix -e secrets/db_password.age
# Editor ochiladi, parol kiriting, saqlang
```

configuration.nix:

```nix
{
  age.secrets.db_password.file = ./secrets/db_password.age;

  services.postgresql.initialScript = pkgs.writeText "init.sql" ''
    CREATE USER admin WITH PASSWORD '@PASSWORD@';
  '';
}
```

## 9. SSH key bilan agenix

`secrets.nix`:

```nix
let
  laptop = "ssh-ed25519 AAAA... laptop";
  server = "ssh-ed25519 AAAA... server";
in
{
  "secrets/db_password.age".publicKeys = [ laptop server ];
}
```

Server SSH host key'i bilan ham decrypt qila oladi.

## 10. Secret'lar service'da

`/run/secrets/db_password` — tmpfs (faqat RAM'da).

```nix
{
  systemd.services.myapp = {
    serviceConfig = {
      LoadCredential = "db_password:${config.age.secrets.db_password.path}";
    };
  };
}
```

`%d/db_password` — systemd credential.

## 11. Secrets backup

Master keys:

- `~/.config/sops/age/keys.txt` — vault'da (1Password, etc).
- `~/.config/age/keys.txt`.
- Git repository — yo'q!

Agar key yo'qolsa — secret'lar decrypt qilib bo'lmaydi.

## 12. Bir nechta foydalanuvchi

```yaml
# .sops.yaml
keys:
  - &alice age1abc...
  - &bob age1def...
  - &server age1ghi...
creation_rules:
  - path_regex: secrets/dev/.+
    key_groups:
      - age: [ *alice, *bob, *server ]
  - path_regex: secrets/prod/.+
    key_groups:
      - age: [ *alice, *server ]      # Bob kira olmaydi
```

## 13. Misol — Postgres + API

```nix
{ config, pkgs, ... }:
{
  sops.secrets = {
    postgres_password = {
      owner = "postgres";
      sopsFile = ./secrets/db.yaml;
      key = "password";
    };
    api_key = {
      owner = "myapp";
      sopsFile = ./secrets/api.yaml;
    };
  };

  services.postgresql = {
    enable = true;
    initialScript = pkgs.writeText "init.sql" ''
      \set pw `cat ${config.sops.secrets.postgres_password.path}`
      CREATE USER admin WITH PASSWORD :'pw';
    '';
  };

  systemd.services.myapp = {
    serviceConfig = {
      User = "myapp";
      EnvironmentFile = config.sops.secrets.api_key.path;
    };
    script = "${pkgs.myapp}/bin/myapp";
  };
}
```

## 14. Eng tez-tez uchraydigan xatolar

- **Private key Git'da** — eng yomon, hammasi ochiq.
- **`.sops.yaml`'da public key noto'g'ri** — decrypt ishlamaydi.
- **`age.keyFile` server'ga deploy bo'lmagan** — service start bo'lmaydi.
- **Secret'larni Nix string'da** — Nix store'da clear bo'lib qoladi.
- **`mode = "0640"` lekin owner noto'g'ri** — service o'qiy olmaydi.

## 15. Eng yaxshi amaliyot

- **Private key vault'da** — 1Password, Bitwarden.
- **Bir nechta key** — laptop, server.
- **`mode = "0400"`** — faqat owner o'qiy oladi.
- **Secret rotation** — har 6-12 oyda.
- **Git workflow** — encrypted secret'lar OK.

**(b)** Faqat memory'da — disk'ga yozilmaydi.
