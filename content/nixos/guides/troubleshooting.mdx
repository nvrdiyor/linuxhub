NixOS muammolarining ko'pi configuration'dagi xato. Rollback eng kuchli vositangiz.[¹](https://nix.dev/recipes/)

## 1. `nixos-rebuild switch` xato

```
error: attribute 'foo' missing
```

- `configuration.nix` da yozish xatosi.
- Mavjud opsiyani noto'g'ri nomda.
- Yechim: [search.nixos.org/options](https://search.nixos.org/options) da to'g'ri nomni topib qo'ying.

## 2. Tizim yuklanmasdi

GRUB menyusida **eski generatsiya** ni tanlang. So'ng:

```bash
# Tizim ishlamoqda — eski generatsiya bilan
# Configuration.nix ni tuzating
sudo nano /etc/nixos/configuration.nix

# Yana qo'llang
sudo nixos-rebuild switch
```

## 3. Disk to'lgan

Nix store ko'p paket versiyalarini saqlaydi:

```bash
# Qancha
du -sh /nix/store

# Eski generatsiyalarni o'chirish
sudo nix-collect-garbage --delete-older-than 30d

# Hammasini (faqat joriy qoldirish)
sudo nix-collect-garbage -d

# Boot qaytadan
sudo nixos-rebuild boot
```

## 4. Build cheksiz davom etadi

- Tarmoq sekin — Nixpkgs cache'dan yuklab oladi.
- `nixos-rebuild --substituters https://cache.nixos.org` standart cache yoqilganligini tekshiring.
- Yangi paket — manba'dan build qilinadi.
