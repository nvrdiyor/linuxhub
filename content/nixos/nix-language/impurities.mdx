Nix sof funksional til — bir xil kirish doim bir xil chiqish. Lekin real dunyo bilan ishlash kerak: fayl o'qish, tarmoqdan yuklab olish. Bu — **nopoklik (impurity)**.[¹](https://nix.dev/tutorials/first-steps/towards-reproducibility-pinning-nixpkgs.html)

## 1. Sof ifoda

```nix
1 + 1                # har doim 2
"hello" + "!"        # har doim "hello!"
```

## 2. Nopok ifoda

```nix
builtins.currentTime     # har chaqirishda boshqacha
builtins.getEnv "USER"   # tizim foydalanuvchisi
```

Nopok ifodalar **takrorlanmaydi**. Nix ularni **iloji boricha cheklaydi**.

## 3. Fayl ilovalari

```nix
./fayl.txt              # joriy katalogga nisbatan
./../config.nix         # otaga
/etc/passwd             # absolyut
```

Bu yo'llar Nix store'ga **nusxalanadi** — kelajakda asl fayl o'zgarsa ham, Nix shu nusxa bilan ishlaydi.

```nix
let
  config = builtins.readFile ./config.txt;
in
"Sozlama: ${config}"
```

## 4. Tarmoq — `fetchurl`, `fetchTarball`

```nix
builtins.fetchurl {
  url = "https://example.com/file.tar.gz";
  sha256 = "sha256-...";
}
```

`sha256` majburiy — fayl yaxlitligi tekshiriladi. Aksi holda — har chaqirish nopok.

```nix
builtins.fetchTarball {
  url = "https://github.com/NixOS/nixpkgs/archive/abc.tar.gz";
  sha256 = "sha256-...";
}
```

`sha256` bilan — sof; `sha256` siz — nopok va keshlanmaydi.

## 5. Pure vs Impure eval

Nix ikki rejimda ishlay oladi:

- **Pure eval mode** — `<nixpkgs>`, env vars, current time — yo'q. To'liq takrorlanish.
- **Impure mode** (default) — yuqoridagilar mavjud.

Flake'lar default'da pure mode'da.

```bash
nix-instantiate --eval --strict --pure-eval ...
```

## 6. Tavsiya

- **Loyihangizda har doim `sha256` bilan `fetchurl`** ishlatilsin.
- **Aniq commit pin** (`https://github.com/.../archive/<commit>.tar.gz`) — `nixos-24.05` kabi reliz nomidan ham aniqroq.
- **`builtins.currentTime`** dan saqlanish — log uchun foydali, lekin build natijasini o'zgartirsa — muammo.

## 7. Mashq

`shell.nix` da `fetchTarball` ishlatib Nixpkgs ni pin qiling (avvalgi darslarda ko'rdik).

## 8. Bilim sinovi

**Savol 1.** `builtins.fetchurl` sof qachon?

- a) Hech qachon
- b) `sha256` argument berilgan bo'lsa
- c) Faqat HTTPS bilan
- d) Doim sof
