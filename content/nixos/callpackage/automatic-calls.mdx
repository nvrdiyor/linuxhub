`callPackage` ichida funksiyaning parametrlarini introspekt qiladi va mos qiymatlarni o'tkazadi. Bu Nix'ning **introspeksiya** xususiyatidan foydalanadi.[¹](https://nix.dev/tutorials/callpackage.html)

## 1. `builtins.functionArgs`

```nix
let
  f = { a, b, c }: a + b + c;
in
builtins.functionArgs f
# { a = false; b = false; c = false; }
```

`false` — argument default'siz; `true` — default bor.

## 2. `callPackage` algoritm

```nix
callPackage = path: extra:
  let
    f = import path;
    args = builtins.functionArgs f;
    matchedArgs = builtins.intersectAttrs args pkgs;
  in
  f (matchedArgs // extra);
```

Soddalashtirib:

1. Faylni import — funksiya oling.
2. Argumentlar ro'yxatini oling.
3. `pkgs` dan mos nomlarni oling.
4. Foydalanuvchining `extra` o'zgaruvchilarini override qiling.
5. Funksiyani chaqiring.

## 3. `callPackageWith`

Agar siz `pkgs` o'rniga boshqa skop bilan ishlamoqchi bo'lsangiz:

```nix
let
  myScope = {
    inherit (pkgs) stdenv;
    openssl = pkgs.openssl_3_2;
    customLib = ./my-lib;
  };

  myCallPackage = pkgs.lib.callPackageWith myScope;
in
myCallPackage ./myapp.nix {}
```

Bu loyiha ichida ko'p paketlar bir xil "custom" `openssl` versiyasini ishlatishi mumkin.

## 4. Override paketlar

```nix
let
  pkgs = import <nixpkgs> {};

  myFirefox = pkgs.firefox.override {
    cfg = { jpegSupport = true; };
  };
in
myFirefox
```

`override` — paket funksiyasiga turli argumentlarni qaytarish.

## 5. Mashq

`nix repl` da:

```nix
nix-repl> let pkgs = import <nixpkgs> {}; in builtins.functionArgs (import (pkgs.path + "/pkgs/applications/networking/browsers/firefox/common.nix"))
# { ... }
```
