`callPackage` — Nixpkgs'ning **eng asosiy** funksiyalaridan biri. U paket funksiyasiga avtomatik kerakli argumentlarni o'tkazadi.[¹](https://nix.dev/tutorials/callpackage.html)

## 1. Muammo

Sizning paketingiz:

```nix
# myapp.nix
{ stdenv, fetchurl, openssl, zlib }:
stdenv.mkDerivation { ... }
```

Chaqirish:

```nix
import ./myapp.nix {
  inherit (pkgs) stdenv fetchurl openssl zlib;
}
```

Argumentlar har safar qo'lda yozish — uzun va xatolarga moyil.

## 2. `callPackage` yechim

```nix
pkgs.callPackage ./myapp.nix {}
```

`callPackage` paket funksiyasining argumentlarini qaraydi va Nixpkgs'dagi mos paketlarni avtomatik o'tkazadi.

## 3. Maxsus argument

Agar siz biron narsani override qilmoqchi bo'lsangiz:

```nix
pkgs.callPackage ./myapp.nix {
  openssl = pkgs.openssl_3_2;    # boshqa versiya
}
```

`{}` bo'sh bo'lsa — hamma narsa default.

## 4. Mashq

`hello.nix` ni `callPackage` orqali build qiling:

```bash
nix-build -E 'with import <nixpkgs> {}; callPackage ./hello.nix {}'
```

## 5. Bilim sinovi

**Savol 1.** `callPackage` nima qiladi?

- a) Paketni o'rnatadi
- b) Funksiyaga avtomatik mos argumentlarni o'tkazadi
- c) Yangi paket yaratadi
- d) Hech narsa

<Callout type="success" title="Javob">
**(b)** `callPackage` `func.params` orqali kerakli argumentlarni `pkgs` dan oladi.
</Callout>
