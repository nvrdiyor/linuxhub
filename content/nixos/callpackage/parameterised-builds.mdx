Ko'p paketlar **variant** build'larni qo'llab-quvvatlaydi — masalan, "X11 bilan" va "X11 siz". Bu paket funksiyasiga qo'shimcha parametrlar orqali amalga oshiriladi.[¹](https://nix.dev/tutorials/callpackage.html)

## 1. Paket misoli

```nix
# myapp.nix
{ stdenv, fetchurl
, enableSSL ? true
, enableHTTP2 ? false
, openssl
}:

stdenv.mkDerivation {
  pname = "myapp";
  version = "1.0";
  src = fetchurl { ... };

  buildInputs = stdenv.lib.optionals enableSSL [ openssl ];

  configureFlags = [
    (stdenv.lib.optionalString enableSSL "--with-ssl")
    (stdenv.lib.optionalString enableHTTP2 "--with-http2")
  ];
}
```

## 2. Variant chaqirish

```nix
let
  pkgs = import <nixpkgs> {};

  myapp = pkgs.callPackage ./myapp.nix {};                  # default
  myappNoSSL = pkgs.callPackage ./myapp.nix { enableSSL = false; };
  myappHTTP2 = pkgs.callPackage ./myapp.nix { enableHTTP2 = true; };
in
{ inherit myapp myappNoSSL myappHTTP2; }
```

## 3. Nixpkgs misol — `ffmpeg`

```nix
pkgs.ffmpeg_6.override {
  withAlsa = true;
  withVulkan = true;
  withWebp = false;
}
```

`override` — paket funksiyasini turli argumentlar bilan qayta chaqirish.

## 4. `overrideAttrs` — derivation atributlari

```nix
pkgs.vim.overrideAttrs (old: {
  version = "9.1";
  src = pkgs.fetchurl {
    url = "https://...";
    sha256 = "...";
  };
})
```

`override` vs `overrideAttrs`:

- `override` — paket funksiyasining **argumentlari**.
- `overrideAttrs` — `mkDerivation` ga uzatilgan **atributlar**.
