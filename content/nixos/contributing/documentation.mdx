NixOS hujjatlari ham ko'ngillilar tomonidan saqlanadi. Sizning hissa qo'shishingiz katta yordam.[¹](https://nix.dev/contributing/)

## 1. Hujjat manbalar

| Sahifa | Repository |
|---|---|
| [NixOS Manual](https://nixos.org/manual/nixos/stable/) | `nixpkgs/nixos/doc/manual` |
| [Nixpkgs Manual](https://nixos.org/manual/nixpkgs/stable/) | `nixpkgs/doc` |
| [Nix Reference](https://nixos.org/manual/nix/stable/) | `nix/doc/manual` |
| [nix.dev](https://nix.dev/) | `nix-dot-dev/nix.dev` |
| [NixOS Wiki](https://nixos.wiki/) | wiki, direct edit |

## 2. PR jarayoni

1. GitHub'da repository fork.
2. Lokal'da clone.
3. Markdown/AsciiDoc tahrirlash.
4. Lokal preview qilish (har repo bo'yicha ko'rsatma).
5. PR yuborish.

## 3. Misol — Nixpkgs Manual'ga PR

```bash
git clone https://github.com/NixOS/nixpkgs
cd nixpkgs
# Markdown/Docbook tahrirlash
# doc/ ostida

# Lokal build
nix-build doc

# PR yuborish
```

## 4. Yangi paket uchun docs

Paket PR'ga ham `meta.description`, `meta.longDescription` qo'shish — hujjatlash.

## 5. Tarjima

NixOS hujjatlari hozircha asosan inglizcha. Tarjima loyihalar:

- LinuxHub.uz — bu loyiha (o'zbek).
- nixpkgs'da `meta.description` ko'p tilda emas.
