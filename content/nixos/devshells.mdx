**Nix DevShell** — project'ga moslab reproducible dev environment. Bir buyruq bilan barcha bog'liq tool'larni aniq versiyada olish.[¹](https://nix.dev/tutorials/first-steps/dev-environment)

<Callout type="info" title="Bu darsda nimani o'rganasiz">
- `nix-shell` (eski) va `nix develop` (flake).
- Multi-language devShell.
- direnv bilan avtomatik environment.
- shellHook va environment.
- Pinning va lock.
</Callout>

## 1. `shell.nix` (eski)

Project root'da:

```nix
# shell.nix
{ pkgs ? import <nixpkgs> {} }:

pkgs.mkShell {
  buildInputs = with pkgs; [
    nodejs_20
    pnpm
    typescript
  ];

  shellHook = ''
    echo "Welcome to my-project!"
    export NODE_ENV=development
  '';
}
```

```bash
nix-shell
# >>> Welcome to my-project!
# (nix-shell) $ node --version
# v20.x.x

exit       # chiqish
```

## 2. Flake devShell (zamonaviy)

`flake.nix`:

```nix
{
  description = "My project";

  inputs.nixpkgs.url = "github:NixOS/nixpkgs/nixos-24.05";

  outputs = { self, nixpkgs }:
    let
      system = "x86_64-linux";
      pkgs = nixpkgs.legacyPackages.${system};
    in {
      devShells.${system}.default = pkgs.mkShell {
        packages = with pkgs; [
          nodejs_20
          pnpm
          typescript
          postgresql_16
        ];

        shellHook = ''
          echo "DevShell active"
          export DATABASE_URL=postgres://localhost/mydb
        '';
      };
    };
}
```

```bash
nix develop
# Yoki
nix develop .#default
```

## 4. direnv integration

`.envrc`:

```bash
use flake
```

```bash
direnv allow
```

Endi katalogga kirsangiz — avtomatik environment yoqiladi. Chiqsangiz — o'chadi.

`direnv` o'rnatish:

```bash
# Ubuntu/Debian
sudo apt install -y direnv

# NixOS
environment.systemPackages = [ pkgs.direnv ];

# Shell hook (~/.bashrc yoki ~/.zshrc)
eval "$(direnv hook bash)"
```

## 5. nix-direnv (kesh)

```bash
nix.extraOptions = ''

  direnv
  nix-direnv

```

`.envrc`:

Birinchi `direnv allow` keyingi kirishlar tezroq.

## 6. Python project

`flake.nix`:

```nix
{
  inputs.nixpkgs.url = "github:NixOS/nixpkgs/nixos-24.05";

  outputs = { self, nixpkgs }:
    let
      pkgs = nixpkgs.legacyPackages.x86_64-linux;
      python = pkgs.python311.withPackages (ps: with ps; [
        flask
        sqlalchemy
        pytest
        black
        mypy
      ]);
    in {
      devShells.x86_64-linux.default = pkgs.mkShell {
        packages = [ python pkgs.postgresql_16 ];

        shellHook = ''
          export FLASK_APP=app.py
          export FLASK_ENV=development
        '';
      };
    };
}
```

```bash
nix develop
python -c "import flask; print(flask.__version__)"
```

## 8. Rust project

```nix

  inputs = {
    nixpkgs.url = "github:NixOS/nixpkgs/nixos-24.05";

  outputs = { self, nixpkgs, rust-overlay }:
```

## 9. Multiple shells

```nix
{
  devShells.x86_64-linux = {
    default = pkgs.mkShell {
      packages = with pkgs; [ nodejs_20 ];
    };

    backend = pkgs.mkShell {
      packages = with pkgs; [ python311 postgresql_16 redis ];
    };

    frontend = pkgs.mkShell {
      packages = with pkgs; [ nodejs_20 pnpm ];
    };

    deploy = pkgs.mkShell {
      packages = with pkgs; [ kubectl helm terraform awscli2 ];
    };
  };
}
```

```bash
nix develop .#backend
nix develop .#frontend
nix develop .#deploy
```

## 10. PostgreSQL DevShell

```nix
{
  devShells.x86_64-linux.default = pkgs.mkShell {
    packages = [ pkgs.postgresql_16 ];

    shellHook = ''
      export PGDATA="$PWD/.postgres"
      export PGHOST="$PGDATA"
      export DATABASE_URL="postgres://localhost/mydb?host=$PGDATA"

      if [ ! -d "$PGDATA" ]; then
        initdb --auth=trust --no-locale --encoding=UTF8
        echo "unix_socket_directories = '$PGDATA'" >> $PGDATA/postgresql.conf
      fi

      pg_ctl -D $PGDATA -l logfile start || true
      createdb mydb 2>/dev/null || true
    '';
  };
}
```

Project ichida — to'liq PostgreSQL.

## 11. Docker bilan farqi

| Xususiyat | Nix DevShell | Docker |

## 14. Eng tez-tez uchraydigan xatolar

- **Old `shell.nix` + flake bir vaqtda** — konflikt.
- **`<nixpkgs>` channel'siz** — flake'da kerak emas.
- **`direnv allow` qilmaslik** — envrc ishlamaydi.
- **Katta paket'lar yangi build** — `cachix` ishlatish.
- **`packages` vs `buildInputs`** — flake'da `packages`.

## 15. Eng yaxshi amaliyot

- **`flake.nix` Git'da** — versiya nazorat.
- **`direnv` + `nix-direnv`** — har vaqt to'g'ri muhit.
- **`shellHook`** — environment va init.
- **Multiple shells** — backend, frontend alohida.
- **Cachix CI'da** — build tezligi.
