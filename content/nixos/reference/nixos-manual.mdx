NixOS — Nix asosida qurilgan butun operatsion tizim. Reference — [NixOS Manual](https://nixos.org/manual/nixos/stable/).[¹](https://nixos.org/manual/nixos/stable/)

## Asosiy bo'limlar

- **Installation** — o'rnatish.
- **Configuration** — `configuration.nix`.
- **Modules** — modul tizimi.
- **Services** — barcha tayyor xizmatlar.
- **Networking** — tarmoq sozlash.
- **Security** — xavfsizlik.
- **Maintenance** — generatsiyalar, garbage collection.

## Tezkor tooling

- **`nixos-rebuild`** — tizim qurish.
- **`nixos-generate-config`** — initial configuration.
- **`nixos-install`** — ISO'dan o'rnatish.
- **`nixos-version`** — versiya.
- **`nix-env`** — paket boshqaruvi (foydalanuvchi).
- **`nix-collect-garbage`** — tozalash.
