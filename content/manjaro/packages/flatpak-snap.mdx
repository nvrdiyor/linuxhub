Flatpak va Snap — distributivga bog'liq bo'lmagan universal paket formatlari. Manjaro ikkalasini ham qo'llab-quvvatlaydi.[¹](https://flatpak.org/setup/Manjaro)[²](https://snapcraft.io/docs/installing-snap-on-manjaro)

<Callout type="info" title="Bu darsda nimani o'rganasiz">
- Flatpak va Snap o'rnatish.
- Flathub orqali paket olish.
- Snap Store.
- Pamac orqali GUI integratsiya.
</Callout>

## 1. Flatpak

### O'rnatish

Manjaro'da `flatpak` paketi default keladi (yo'q bo'lsa):

```bash
sudo pacman -S flatpak
```

### Flathub repozitoriya

Asosiy Flatpak repo — Flathub:[³](https://flathub.org/)

```bash
flatpak remote-add --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
```

So'ng qayta loginlanish yoki tizimni qayta yuklash.

### Foydalanish

```bash
# Qidirish
flatpak search "video editor"

# O'rnatish
flatpak install flathub com.spotify.Client

# Ishga tushirish
flatpak run com.spotify.Client

# Yoki ish stolida iconni ko'rasiz

# Ro'yxat
flatpak list

# Yangilash
flatpak update

# O'chirish
flatpak uninstall com.spotify.Client

# Foydalanilmayotgan runtime'larni tozalash
flatpak uninstall --unused
```

## 2. Snap

### O'rnatish

```bash
# Snap rasmiy repo'da yo'q — AUR'dan
yay -S snapd

# Yoki: AUR helper bilan
pamac install snapd

# Yoqish
sudo systemctl enable --now snapd.socket

# Symlink (classic Snap'lar uchun)
sudo ln -s /var/lib/snapd/snap /snap
```

So'ng logout va login (PATH yangilanishi uchun).

### Foydalanish

```bash
# Qidirish
snap find code

# O'rnatish
sudo snap install code --classic

# Ro'yxat
snap list

# Yangilash
sudo snap refresh

# O'chirish
sudo snap remove code
```

## 3. Pamac orqali GUI

Pamac avtomatik Flatpak va Snap'ni qo'llab-quvvatlaydi. Yoqish:

```
Pamac → Preferences → Third Party → Enable Flatpak / Enable Snap → Apply
```

Endi qidirishda har bir natija manbai ko'rsatiladi: `Official`, `AUR`, `Flatpak`, `Snap`.

## 4. Flatpak vs Snap vs AUR

| | Flatpak | Snap | AUR |
|---|---|---|---|
| Manba | Flathub va boshqalar | Snap Store | Hamjamiyat (PKGBUILD) |
| Markazlashtirilgan | Yo'q | Ha (Canonical) | Yo'q |
| Hajm | Katta | Eng katta | Kichik (native) |
| Tezlik | O'rta | Sekinroq (mount squashfs) | Eng tez (native) |
| Sandbox | Bportland | AppArmor + namespace | Yo'q |
| Manjaro integratsiya | Yaxshi | O'rta | Eng yaxshi |

**Tavsiya Manjaro'da:** rasmiy repo > AUR > Flatpak > Snap.

## 5. Misol: Spotify

3 ta usul:

```bash
# AUR
yay -S spotify

# Flatpak
flatpak install flathub com.spotify.Client

# Snap
sudo snap install spotify
```

Tezlik va integratsiya bo'yicha AUR > Flatpak > Snap.

## 6. Buyruqlar va izoh

| Buyruq | Vazifa |
|---|---|
| `flatpak search <so'z>` | Flatpak qidirish |
| `flatpak install flathub <id>` | Flatpak o'rnatish |
| `flatpak list` | Ro'yxat |
| `flatpak update` | Yangilash |
| `flatpak uninstall --unused` | Tozalash |
| `snap find <so'z>` | Snap qidirish |
| `sudo snap install <paket>` | O'rnatish |
| `sudo snap refresh` | Yangilash |
| `snap list` | Ro'yxat |

## 7. Eng tez-tez uchraydigan xatolar

- **Flathub yoqilmagan** — `flatpak install` yangi paketga yo'q.
- **Snap symlink yo'q** — `sudo ln -s /var/lib/snapd/snap /snap` kerak (classic snaplar uchun).
- **Snap PATH'da yo'q** — logout va login yoki `source /etc/profile.d/apps-bin-path.sh`.
- **Ikki manba'dan bir xil paket** — Pamac dublikatlarni ko'rsatadi, tanlash kerak.

## 8. Eng yaxshi amaliyot

- **Rasmiy repo birinchi** — eng tez va integratsiya.
- **AUR ikkinchi** — agar repo'da yo'q.
- **Flatpak uchinchi** — agar sandbox kerak yoki ko'p versiya.
- **Snap eng oxir** — Manjaro'da kamroq integratsiya.
- **Bir dasturni faqat bir formatda** — RAM va disk tejash.
