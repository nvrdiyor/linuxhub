Manjaro bir necha rasmiy va community DE'larini taklif qiladi. Tanlash sizning didingiz va apparat resurslaringizga bog'liq.[¹](https://manjaro.org/download/)

<Callout type="info" title="Bu darsda nimani o'rganasiz">
- 3 ta rasmiy DE: XFCE, GNOME, KDE.
- Community DE'lar (i3, Sway, Cinnamon va boshqalar).
- O'rnatilgan tizimga DE qo'shish.
</Callout>

## 1. Rasmiy Manjaro DE'lar

### XFCE

- **Falsafa:** Yengil, klassik, sodda.
- **RAM:** ~600 MB ishga tushganda.
- **Default Manjaro DE.**
- **Mos:** eski apparat, batareya tejash, klassik UX.

### GNOME

- **Falsafa:** Modern, sodda, mobile-uslubdagi.
- **RAM:** ~1.5 GB.
- **Mos:** Modern apparat, sodda UX, hozirgi standart.

### KDE Plasma

- **Falsafa:** To'liq, moslashtirish imkoniyatlari ko'p.
- **RAM:** ~700 MB (oxirgi versiyalar yengilroq).
- **Mos:** Moslashtirishni xohlaganlar, Windows'dan o'tgan foydalanuvchilar.

## 2. Community DE'lar

Manjaro Community Editions [manjaro.org/download](https://manjaro.org/download/) sahifasining pastida:

- **Cinnamon** — Mint asosida, Windows-uslubdagi.
- **Budgie** — Solus loyihasi.
- **MATE** — GNOME 2 ning davomi.
- **i3** — tile window manager (klaviatura).
- **Sway** — Wayland tile WM.
- **LXQt** — eng yengil.

## 4. O'rnatilgan tizimga DE qo'shish

Bir DE'dan boshlab boshqasini sinab ko'rish mumkin:

```bash
# XFCE
sudo pacman -S manjaro-xfce-settings xfce4 xfce4-goodies

# GNOME
sudo pacman -S gnome gnome-extra manjaro-gnome-settings

# KDE Plasma
sudo pacman -S plasma kde-applications manjaro-kde-settings

# i3
sudo pacman -S i3-gaps i3status i3lock dmenu rofi

# Display manager (login screen) ni o'zgartirish (agar kerak)
sudo systemctl disable lightdm
sudo systemctl enable sddm    # KDE uchun
# yoki
sudo systemctl enable gdm     # GNOME uchun
```

Logout va login ekranida DE'ni tanlash mumkin.

| 4-8 GB RAM, kundalik | KDE Plasma yoki GNOME |
| 8 GB+, dizayn | GNOME |
| Server yoki minimal | i3/Sway |
| Windows'dan o'tgan | Cinnamon yoki KDE |

## 7. Manjaro standart sozlash

Manjaro har DE'da o'zining temalari va sozlamalarini qo'shadi:

- **Matcha** rangi — yashil aksent.
- **Papirus** iconlari.
- **Cantarell / Noto** shriftlar.
- **Plank** dock (XFCE'da).

Bu Manjaro'ni tanib olishni osonlashtiradi.

## 8. Mashqlar

1. Hozirgi DE'ningiz nima? `echo $XDG_CURRENT_DESKTOP` — natijani yozing.
2. [manjaro.org/download](https://manjaro.org/download/) ni oching va community editions ro'yxatini sanang.
3. (Ixtiyoriy) Test VM'da boshqa DE'ni qo'shib ko'ring (masalan, XFCE asosida GNOME).
