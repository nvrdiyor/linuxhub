Manjaro Calamares o'rnatuvchisi bilan keladi — grafik, oson, 20-30 daqiqa. Bu darsda bosqichma-bosqich ko'rib chiqamiz.[¹](https://wiki.manjaro.org/index.php/Installation_with_the_Graphical_Installer)

<Callout type="info" title="Bu darsda nimani o'rganasiz">
- ISO yuklab olish va SHA tekshiruvi.
- Bootable USB.
- Calamares qadamlar.
</Callout>

## 1. ISO yuklab olish

[manjaro.org/download](https://manjaro.org/download/) dan tanlang:

- **XFCE** — yengil, default.
- **GNOME** — modern.
- **KDE Plasma** — to'liq.

SHA tekshiruvi:

```bash
# Linux/macOS
sha256sum manjaro-xfce-XX.X-stable-x86_64.iso

# Windows PowerShell
Get-FileHash manjaro-xfce-XX.X-stable-x86_64.iso -Algorithm SHA256
```

## 2. Bootable USB

### Windows — Rufus

1. Rufus oching.
2. USB tanlang (8 GB+).
3. ISO tanlang.
4. **DD Image mode** ni tavsiya — Manjaro ko'pincha ISO Hybrid mode'da yaxshi ishlaydi.
5. START.

### Linux — `dd`

```bash
lsblk    # USB qaysi qurilma

sudo dd if=manjaro-xfce-XX.X-stable-x86_64.iso of=/dev/sdb bs=4M status=progress conv=fdatasync
```

## 3. USB'dan yuklash

1. Kompyuterni o'chiring, USB ulang, yoqing.
2. Boot menyu (`F12`, `F10`, `Esc`).
3. USB tanlang.
4. GRUB:
   - **Boot with open source drivers** — default.
   - **Boot with proprietary drivers** — NVIDIA va boshqa.
5. Live session ochiladi. Ish stoli'da **Install Manjaro** iconini bosing.

## 5. Birinchi yuklanishdan keyin

```bash
# Versiya
cat /etc/lsb-release

# Yangilash (Manjaro Stable branchda — sinovdan o'tgan paketlar)
sudo pacman -Syu

# Hardware autodetect — kerakli drayverlarni avtomatik
sudo mhwd -a pci free 0300       # bepul drayverlar
sudo mhwd -a pci nonfree 0300    # nonfree (NVIDIA proprietary)
```

## 6. Manjaro Hello — birinchi yordamchi

Birinchi yuklanishda **Manjaro Hello** dasturi ochiladi. U taklif qiladi:

- Tilni o'zgartirish.
- Drayverlarni o'rnatish.
- Asosiy ilovalarni tanlash.
- Hujjatlar va forum havolasi.

Yangi foydalanuvchilarga **juda foydali**.

## 7. Mashqlar

1. (Virtual mashinada) Manjaro XFCE'ni o'rnating. Calamares qadamlarni eslang.
2. O'rnatishdan keyin `mhwd -li` — qaysi drayverlar avtomatik o'rnatilgan?
3. `pacman -Syu` ni bajaring — yangilanishlar bormi?
