## 1. Parolni hech kim saqlamaydi (to'g'ri ishlangan)

Hech qanday xizmat parolni "ochiq matnda" saqlamasligi kerak. O'rniga **hash funksiyasi** ishlatiladi.

```
Parol  ──▶  Hash funksiyasi  ──▶  Xesh qiymati
"password123"     SHA-256       "ef92b778bafe..."
```

**Asosiy xususiyatlar:**

- Bir tomonlama — xeshdan parolni tiklash imkonsiz (ideal holda).
- Bir xil kirish — har doim bir xil chiqish.
- Kichik o'zgarish — butunlay boshqa xesh.

## 2. Eski hash funksiyalari (ishlatmang!)

| Hash | Holat | Sabab |
|---|---|---|
| MD5 | Buzilgan | Kolliziya hujumlari |
| SHA-1 | Buzilgan | Kolliziya |
| Plain SHA-256 | Yaroqsiz parol uchun | Tez — brute-force tezroq |

## 3. To'g'ri hash funksiyalari (parol uchun)

Maxsus "sekin" hash funksiyalari ishlab chiqilgan — brute-force qiyinroq qilish uchun:

- **bcrypt** — eski (1999), hali ham yaxshi.
- **scrypt** — RAM ham talab qiladi.
- **Argon2** — 2015-yil Password Hashing Competition g'olibi. **Tavsiya etiladi.**
- **PBKDF2** — NIST standart, lekin GPU'larda zaif.

[NIST SP 800-63B](https://pages.nist.gov/800-63-3/sp800-63b.html) — Argon2id yoki bcrypt tavsiya etadi.[³](https://pages.nist.gov/800-63-3/sp800-63b.html)

## 4. Salt va Pepper

**Salt** — har bir foydalanuvchi uchun unikal tasodifiy qiymat. U xesh bilan birga saqlanadi.

```
Foydalanuvchi: ali
Parol:         "password123"
Salt:          "X8j2K9..."
Hash funksiyasi: bcrypt(parol + salt)
Saqlanadi:     "$2b$12$X8j2K9.../h7s2L9d4..."
```

**Pepper** — qo'shimcha sekret qiymat (server tomonida, DB'da emas). Agar DB sizdiri bo'lsa ham, pepper himoya beradi.

## 5. `/etc/shadow` ichida

```
ali:$6$xyz$abc...:19500:0:99999:7:::
```

`$6$` = SHA-512 crypt.

| `$` qiymati | Hash |
|---|---|
| `$1$` | MD5 |
| `$2y$` | bcrypt |
| `$5$` | SHA-256 |
| `$6$` | SHA-512 |
| `$y$` | yescrypt (zamonaviy default ko'p distributivlarda) |

## 6. John the Ripper — klassik vosita

[John the Ripper](https://www.openwall.com/john/) — 1996-yildan beri faol rivojlanayotgan parol audit vositasi.[¹](https://www.openwall.com/john/doc/)

```bash
# Kali'da default o'rnatilgan
john --help

# `/etc/shadow` formatidagi faylni sinab ko'rish (FAQAT O'Z TIZIMINGIZ)
sudo cp /etc/shadow /tmp/mypasswd.hash

# Wordlist asosida
john --wordlist=/usr/share/wordlists/rockyou.txt /tmp/mypasswd.hash

# Natijalarni ko'rish
john --show /tmp/mypasswd.hash
```

`rockyou.txt` — Kali'da default keladi (siqilgan):

```bash
sudo gunzip /usr/share/wordlists/rockyou.txt.gz
```

## 7. Hashcat — GPU asoslangan

[Hashcat](https://hashcat.net/) — GPU bilan birga ishlaganda ko'p marta tezroq.[²](https://hashcat.net/wiki/)

```bash
# Hash turi ID'larini ko'rish
hashcat --help | less

# Misol: MD5 (mode 0)
echo -n "password123" | md5sum
# 482c811da5d5b4bc6d497ffa98491e38

echo "482c811da5d5b4bc6d497ffa98491e38" > /tmp/hash.txt

hashcat -m 0 /tmp/hash.txt /usr/share/wordlists/rockyou.txt

# bcrypt (mode 3200)
hashcat -m 3200 /tmp/bcrypt.txt /usr/share/wordlists/rockyou.txt
```

Asosiy modlar:

| Mode | Hash |
|---|---|
| 0 | MD5 |
| 100 | SHA-1 |
| 1400 | SHA-256 |
| 1800 | SHA-512 Unix |
| 3200 | bcrypt |
| 22000 | WPA-PBKDF2-PMKID+EAPOL (Wi-Fi) |

## 8. Hujum turlari

| Hujum | Tavsif |
|---|---|
| **Dictionary** | Wordlist'dan parol qidiruv |
| **Brute-force** | Hamma kombinatsiyalar |
| **Rule-based** | Wordlist + qoidalar (`password` → `Password1!`) |
| **Mask** | Aniq pattern (`?d?d?d?d` = 4 raqam) |
| **Hybrid** | Wordlist + brute-force qism |

```bash
# Mask misol — 4 raqam
hashcat -m 0 -a 3 /tmp/hash.txt ?d?d?d?d

# Rule asosida
hashcat -m 0 -r /usr/share/hashcat/rules/best64.rule /tmp/hash.txt wordlist.txt
```

## 9. Vaqt va imkoniyat

Misol — bcrypt cost 12 (default Apache, ko'p framework'lar):

- 1 GPU (RTX 3080): ~10 hash/sec.
- 10 ta belgi (lowercase + digit): ~6 ming yil.
- **Bcrypt brute-force amalda imkonsiz.**

Misol — SHA-256 (cheksiz tez):

- 1 GPU: ~5 mlrd hash/sec.
- 8 ta belgi (lowercase + digit): ~5 daqiqada.

**Xulosa:** to'g'ri hash funksiyasi (Argon2/bcrypt) — eng katta himoya.

## 10. Defensive — bu darsning eng muhim qismi

### Foydalanuvchi sifatida

- **Uzun parol** (16+ belgi) — kichik shortdan ko'ra muhimroq.
- **Password manager** — har xizmatga unikal parol (1Password, Bitwarden, KeePassXC).
- **MFA (Multi-Factor Authentication)** — har joyda yoqing. Hatto parol o'g'irlangan bo'lsa, MFA to'sadi.
- **Pwned tekshirish:** [haveibeenpwned.com](https://haveibeenpwned.com/) — sizning emailingiz buzilgan DB'larda?

### Tizim/dastur dasturchi sifatida

- **Argon2id yoki bcrypt** ishlatish. SHA-256/MD5 yo'q.
- **Unikal salt** har foydalanuvchi uchun.
- **Pepper** sekret sifatida (`SECRET_KEY` env'da).
- **Rate limiting** login uchun — 5 marta xato → 5 daqiqa to'xtatish.
- **fail2ban** SSH va boshqa servislar uchun.
- **Lockout** N marta noto'g'ri urinishdan keyin.

## 11. Buyruqlar va izoh

| Buyruq | Vazifa |
|---|---|
| `john --wordlist=<list> <hash>` | Wordlist hujum |
| `john --show <hash>` | Topilgan parollar |
| `hashcat -m <mode> <hash> <list>` | Hashcat hujum |
| `hashcat -a 3 -m <mode> <hash> <mask>` | Mask hujum |
| `hashcat --status` | Real-time progress |
| `echo -n "..." | sha256sum` | Hash hisoblash |

## 12. Eng tez-tez uchraydigan xatolar

- **Boshqalarning xeshlarini sinash** — qonuniy javobgarlik.
- **`/etc/shadow` ni boshqa serverga ko'chirish** — bir uchun audit, lekin tarqatish — xavfsizlik buzilishi.
- **MD5/SHA-256 ni parol uchun** — tezda buziladi.
- **Salt'siz hash** — rainbow table hujumi mumkin.
- **"Mening parolim uzun, MFA kerak emas"** — yo'q. MFA — qo'shimcha qatlam, har doim foydali.

## 13. Eng yaxshi amaliyot

- **Foydalanuvchi sifatida:** Password manager + 16+ belgi + har joyda MFA.
- **Dasturchi sifatida:** Argon2id (default) yoki bcrypt cost 12+, har doim salt.
- **Tizim administratori sifatida:** `/etc/login.defs` da kuchli parol siyosati, `fail2ban`, MFA.
- **`pwgen`** orqali kuchli parol yaratish:

  ```bash
  sudo apt install pwgen
  pwgen -s 24 1
  ```

- **`haveibeenpwned`** orqali muntazam tekshirish.

## 15. Mashq

**Faqat o'z parolingiz bilan:**

1. O'zingiz uchun bir parol toping (`mytest123` kabi). MD5 xeshini hisoblang: `echo -n "mytest123" | md5sum`.
2. Topilgan xeshni `/tmp/test.hash` ga yozing va `hashcat -m 0 /tmp/test.hash /usr/share/wordlists/rockyou.txt --potfile-disable` ishlatib parolni topib ko'rish vaqtini kuting.
3. Qancha vaqt o'tdi? `password123` kabi parol qancha tez topiladi?
4. `pwgen -s 24 1` orqali kuchli parol yarating. Endi xuddi shu hujumni ushbu parol bilan sinab ko'ring.
5. [haveibeenpwned.com](https://haveibeenpwned.com/) ga email manzilingizni kiriting — buzilgan ma'lumotlarda bormi?
