Kali Linux Debian asosida bo'lgani uchun apparat talablari Debian bilan deyarli bir xil. Lekin xavfsizlik vositalari ko'p resurs talab qiladi.[¹](https://www.kali.org/docs/installation/hard-disk-install/)

<Callout type="info" title="Bu darsda nimani o'rganasiz">
- Minimal va tavsiya etilgan apparat.
- Variant tanlovi — to'liq, light, NetHunter va boshqalar.
- Qattiq disk yoki virtual mashina tavsiyalari.
</Callout>

## 1. Minimal talablar (Kali rasmiy docs)

| Resurs | Minimal | Tavsiya etilgan |
|---|---|---|
| Protsessor | 1 GHz | 2+ yadroli, 2 GHz+ |
| RAM | 2 GB (Xfce uchun) | 4-8 GB |
| Disk | 20 GB | 50+ GB |
| Tarmoq | Internet (o'rnatish va yangilanish uchun) | — |

Bu minimal — vositalar bilan ishlash uchun ko'proq kerak (masalan, Burp Suite Java asoslangan, 4 GB+ RAM yaxshi).

## 2. Default desktop

Kali 2019.4 dan boshlab **Xfce** default desktop muhiti. Boshqa variantlar:

- Kali GNOME
- Kali KDE
- Kali MATE
- Kali LXDE
- Kali i3 (window manager)

## 3. Image variantlari

Kali rasmiy [download sahifasidan](https://www.kali.org/get-kali/) yuklab olish mumkin:

| Variant | Tavsif |
|---|---|
| **Installer Images** | To'liq o'rnatish (Live va Installer ISO) |
| **Virtual Machines** | VMware va VirtualBox uchun tayyor image |
| **ARM** | Raspberry Pi va boshqa ARM qurilmalar |
| **Mobile (NetHunter)** | Android uchun |
| **Cloud** | AWS, Azure, Linode |
| **Containers** | Docker va LXD |
| **WSL** | Windows Subsystem for Linux |
| **Live Boot** | USB yoki DVD'dan o'rnatishsiz ishlatish |

## 4. Qaysi variantni tanlash?

| Vaziyat | Tavsiya |
|---|---|
| Boshlovchi, sinab ko'rmoqchi | **Virtual Machine** (VMware/VirtualBox) |
| Doimiy ish kompyuteri | **Installer** (to'liq o'rnatish) |
| O'rnatishsiz sinash | **Live Boot USB** |
| Mobil sinov | **Kali NetHunter** (Android) |
| Cloud lab | **Cloud Images** |
| Windows ostida | **WSL** |
| Tezkor konteyner | **Docker** |

## 5. Virtual mashina afzalliklari (tavsiya etiladi)

Boshlovchilar uchun **virtual mashina eng yaxshi tanlov**:

- Asosiy operatsion tizimga ta'sir qilmaydi.
- Snapshot olish va eski holatga qaytish oson.
- Tarmoqdan ajratish mumkin (test labni izolyatsiya qilish).
- Bir nechta Kali instansiyasini bir vaqtda ishlatish.

Virtual mashina uchun apparat:

- Host RAM: 8 GB+ (4 GB Kali'ga ajratish uchun).
- Host disk: 100 GB+ bo'sh joy.
- Virtualization (VT-x/AMD-V) BIOS'da yoqilgan.
