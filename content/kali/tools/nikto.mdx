**Nikto** — Perl'da yozilgan web server vulnerability scanner. 7000+ ma'lum CVE va misconfigure'larni tekshiradi. 1999'dan beri.[¹](https://github.com/sullo/nikto)

<Callout type="warning" title="QONUNIY OGOHLANTIRISH">
Nikto yozma ruxsatsiz target'da ishlatish — jinoyat. Faqat o'z server'ingiz yoki bug bounty platform.
</Callout>

<Callout type="info" title="Bu darsda nimani o'rganasiz">
- Nikto asosiy skan.
- Plugin tuning.
- Specific tests.
- Output formati (JSON, XML, HTML).
- WAF detection.
</Callout>

## 1. O'rnatish

Kali'da default. Ubuntu/Debian:

```bash
sudo apt install -y nikto
```

Versiya:

```bash
nikto -Version
# +- Nikto 2.5.x
```

## 2. Asosiy skan

```bash
nikto -h http://target.com

# HTTPS
nikto -h https://target.com

# Aniq port
nikto -h target.com -p 8080

# Bir nechta port
nikto -h target.com -p 80,443,8080
```

## 4. Tuning — aniq test'lar

```bash
# Faqat misconfiguration
nikto -h target.com -Tuning 1

# Faqat XSS
nikto -h target.com -Tuning 4

# Faqat injection
nikto -h target.com -Tuning 9

# Kombinatsiya
nikto -h target.com -Tuning x

# To'liq ro'yxat
nikto -list-plugins
```

Tuning code'lar:

| Code | Test |
|---|---|
| 1 | Interesting files / misconfig |
| 2 | Misconfiguration / default files |
| 3 | Information disclosure |
| 4 | Injection (XSS/SQL) |
| 5 | Remote file retrieval |
| 6 | Denial of Service |
| 7 | Remote file retrieval — server |
| 8 | Command execution |
| 9 | SQL Injection |
| 0 | File upload |
| a | Authentication bypass |
| b | Software identification |
| c | Remote source inclusion |
| x | Reverse tuning |

## 5. Authentication

```bash
# HTTP Basic
nikto -h target.com -id admin:password

# Cookie
nikto -h target.com -Plugins "headers(realip);ssl" \
    -evasion 1 -Save cookie.txt
```

## 6. SSL/TLS skan

```bash
nikto -h https://target.com -ssl

# Yoki avtomatik (443 port'da)
nikto -h https://target.com
```

## 7. Evasion technique'lar

WAF bypass:

```bash
nikto -h target.com -evasion 1
# 1 — Random URI encoding (non-UTF8)
# 2 — Directory self-reference (/./)
# 3 — Premature URL ending
# 4 — Prepend long random string
# 5 — Fake parameter
# 6 — TAB as request spacer
# 7 — Change the case of the URL
# 8 — Use Windows directory separator (\)
```

Bir nechta:

```bash
nikto -h target.com -evasion 1267
```

## 8. Output

```bash
# Text
nikto -h target.com -o results.txt

# HTML
nikto -h target.com -o results.html -Format html

# XML
nikto -h target.com -o results.xml -Format xml

# JSON
nikto -h target.com -o results.json -Format json

# CSV
nikto -h target.com -o results.csv -Format csv
```

## 9. Database update

```bash
nikto -update
# Yangi CVE va signature'lar
```

## 10. Misol — to'liq audit

```bash
# 1. Asosiy skan
nikto -h https://mysite.com -o scan.html -Format html

# 2. Tuning kengroq
nikto -h https://mysite.com -Tuning 123456789 -ssl \
    -o full-scan.html -Format html

# 3. WAF behind
nikto -h https://mysite.com -evasion 17 -o waf-bypass.html
```

| Tool | Maqsad | Tezligi |

| **Nikto** | Web server misconfig, eski CVE | O'rta |
| **OWASP ZAP** | Full web app pentest | Sekin |
| **Burp Suite** | Manual + auto | Manual |

Nikto — birinchi recon, keyin kerakli'sini chuqurroq.

## 12. Nuclei (Nikto alternativi)

Modern alternativ:

```bash
go install -v github.com/projectdiscovery/nuclei/v3/cmd/nuclei@latest

# Skan
nuclei -u https://target.com

# Aniq template'lar
nuclei -u https://target.com -t cves/
nuclei -u https://target.com -t exposed-panels/
```

Templated va GitHub community'dan.

## 13. Defensive — Nikto natijasi

Asosiy topiladigan zaifliklar:

- **Server version disclosure** — `Server: Apache/2.4.x`.
- **Directory listing** — `Options -Indexes`.
- **Default files** — `/admin/`, `/phpmyadmin/`, `/.git/`.
- **Missing headers** — X-Frame-Options, CSP, HSTS.
- **TRACE method** — `TraceEnable Off`.
- **Default credentials** — admin/admin.

Tuzatish:

```nginx
# nginx
server_tokens off;

add_header X-Frame-Options "SAMEORIGIN" always;
add_header X-Content-Type-Options "nosniff" always;
add_header Strict-Transport-Security "max-age=31536000" always;
add_header Content-Security-Policy "default-src 'self'" always;
```

## 14. Eng tez-tez uchraydigan xatolar

- **Versiya eskirgan** — `nikto -update`.
- **HTTPS skan** — `-ssl` flag yoki `https://`.
- **WAF block** — `-evasion` bilan ham qiyin.
- **Yozma ruxsatsiz** — jinoyat.
- **False positive** — manual tasdiq qilish kerak.

## 15. Eng yaxshi amaliyot

- **Birinchi recon** — Nikto + Nuclei.
- **Manual tasdiq** — har xatolikni qo'lda tekshiring.
- **Output saqlash** — `-Format html` hisobot.
- **Defensive — `server_tokens off`** — versiya disclosure'siz.
- **CI/CD'da** — har deploy'da auto-skan.

## 16. Mashqlar

1. **Lokal:** Nginx default page'ga skan.
2. **DVWA:** Lab muhitida tekshiring.
3. **Output:** HTML report ko'rib chiqing.
4. **Tuning:** Faqat misconfig (Tuning 1).
5. **Defensive:** O'z saytingizdagi muammolarni tuzating.
