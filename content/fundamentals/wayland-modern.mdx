**Wayland** — X11'ning keyingi avlod displey protokoli. 2008'dan rivojlanmoqda, hozir modern Linux desktop standartlariga aylanmoqda. Bu darsda Wayland va X11 o'rtasidagi farqlarni va modern compositor'larni o'rganamiz.[¹](https://wayland.freedesktop.org/)

<Callout type="info" title="Bu darsda nimani o'rganasiz">
- X11 muammolari va Wayland yechimi.
- Compositor turlari (Mutter, KWin, Sway, Hyprland).
- Xwayland — eski ilovalar uchun X11 layer.
- Misol Wayland session sozlash.
- Troubleshooting.
</Callout>

## 1. X11 muammolari

X Window System (1984) — 40+ yoshli protokol. Muammolari:

- **Murakkab arxitektura** — X server + window manager + compositor alohida.
- **Security** — har klient boshqalar oynalarini ko'ra oladi (keylogger trivial).
- **Tearing** — vertikal sinxronlash muammolari.
- **DPI** — multi-monitor turli DPI bilan ishlamaydi.
- **Modular emas** — har display drayveri X server modul'iga muhtoj.

## 2. Wayland yechimi

```
X11:                          Wayland:

[App] ──▶ [X Server] ──▶     [App] ──▶ [Compositor] ──▶ [Display]
              │
              ├── window manager
              ├── compositor
              └── input handling

         Murakkab,             Bittada
         insecure              compositor =
                               WM + Compositor
                               + display server
```

Wayland'da **compositor** — display server, window manager va compositor birgalikda.

| Xususiyat | X11 | Wayland |
|---|---|---|
| Yosh | 1984 | 2008 |
| Arxitektura | Server + WM + Compositor | Compositor (bir narsa) |
| Security | Ochiq (har app boshqalarni ko'radi) | Izolyatsiya |
| Network transparency | Ha | Yo'q (waypipe alohida) |
| Tearing | Ko'p | Yo'q (frame-perfect) |
| Multi-DPI | Yomon | Yaxshi |
| Eski apps | Native | Xwayland orqali |

## 4. Joriy session — Wayland yoki X11?

```bash
# Environment
echo $XDG_SESSION_TYPE
# wayland yoki x11

# loginctl orqali
loginctl show-session $(loginctl | grep $USER | awk '{print $1}') -p Type
```

GDM (GNOME) login screen'ida session tanlash mumkin: "Ubuntu on Wayland" yoki "Ubuntu on Xorg".

## 5. GNOME Wayland (default ko'p distributivlarda)

Ubuntu 21.04+, Fedora 25+ — Wayland default. Hech qanday qo'shimcha sozlash kerak emas.

Tekshirish:

```bash
echo $XDG_SESSION_TYPE
# wayland
```

GNOME ilovalar — native Wayland. Eski X11 ilovalar — Xwayland orqali avtomatik.

## 6. Sway — i3 muqobil

[Sway](https://swaywm.org/) — i3'ga aniq mos Wayland compositor. Keyboard-focused.[³](https://swaywm.org/)

```bash
# O'rnatish
sudo apt install sway

# Login screen'idan tanlash, yoki TTY'dan
sway
```

`~/.config/sway/config` (yoki `/etc/sway/config`'dan nusxa olish):

```
# Modifier
set $mod Mod4

# Terminal
set $term alacritty
bindsym $mod+Return exec $term

# App launcher
set $menu wofi --show drun
bindsym $mod+d exec $menu

# Window navigation (i3 kabi)
bindsym $mod+h focus left
bindsym $mod+j focus down
bindsym $mod+k focus up
bindsym $mod+l focus right

# Window moving
bindsym $mod+Shift+h move left

# Workspaces
bindsym $mod+1 workspace 1
bindsym $mod+2 workspace 2

# Output (monitor)
output HDMI-A-1 resolution 1920x1080 position 0,0
output DP-1 resolution 2560x1440 position 1920,0

# Reload config
bindsym $mod+Shift+c reload
```

## 8. Xwayland — eski X11 ilovalar uchun

Wayland session'da X11 ilovalar **Xwayland** orqali ishlaydi:

```
[X11 App] ──▶ [Xwayland] ──▶ [Wayland Compositor]
```

Tekshirish:

```bash
ps aux | grep Xwayland
```

Foydalanuvchi sezmaydi — avtomatik. Performance asosan native.

## 9. Misollar — qaysi app Wayland native?

| Ilova | Wayland | Eslatma |
|---|---|---|
| Firefox | Native (env bilan) | `MOZ_ENABLE_WAYLAND=1` |
| Chromium/Chrome | Flag bilan | `--enable-features=UseOzonePlatform --ozone-platform=wayland` |
| GIMP | Xwayland | 3.0 versiyada native |
| Inkscape | Xwayland | |
| LibreOffice | Xwayland | |
| VS Code | Flag bilan | `--enable-features=UseOzonePlatform --ozone-platform=wayland` |
| Steam | Xwayland | |
| GNOME ilovalar | Native | |

### Firefox Wayland yoqish

```bash
# Vaqtinchalik
MOZ_ENABLE_WAYLAND=1 firefox

# Doimiy
echo "export MOZ_ENABLE_WAYLAND=1" >> ~/.bashrc
```

Yoki `~/.config/environment.d/wayland.conf`:

```
MOZ_ENABLE_WAYLAND=1
```

## 10. Screen sharing — Wayland muammosi

X11'da screen sharing oson edi — har app ekranni ko'ra olardi. Wayland'da xavfsizlik uchun — yo'q.

Yechim: **PipeWire** + **xdg-desktop-portal**:

```bash
sudo apt install pipewire pipewire-pulse wireplumber \
    xdg-desktop-portal xdg-desktop-portal-gtk xdg-desktop-portal-wlr
```

So'ng Zoom, OBS, Chrome — `xdg-desktop-portal` orqali ekran tanlash dialog'i ko'rsatadi.

## 11. Tarmoq orqali ekran — `waypipe`

X11'da `ssh -X` orqali GUI ilovalar. Wayland'da:

```bash
sudo apt install waypipe

# Server'da app ishga tushirish
waypipe ssh user@server -- firefox
```

Local'da Wayland compositor'da ko'rinadi.

## 12. Screenshot va screen recording

```bash

grim screenshot.png
grim -g "$(slurp)" selection.png

sudo apt install wf-recorder
wf-recorder -f video.mp4
```

KDE — `Spectacle`.

## 13. NVIDIA va Wayland

NVIDIA proprietary drayver tarixiy Wayland'da yomon edi. **NVIDIA 525+** dan boshlab yaxshilanmoqda.

Hozirgi holatda:

- GNOME + NVIDIA 525+ — yaxshi ishlaydi.
- Sway/Hyprland + NVIDIA — eksperimental, ko'p issue.

Alternativa: **nouveau** (open-source) yoki Intel/AMD GPU.

## 15. Eng tez-tez uchraydigan xatolar

- **`xrandr` Wayland'da ishlamaydi** — display sozlash compositor orqali (GNOME Settings, `wlr-randr`).
- **`xdotool`, `wmctrl`** ham ishlamaydi — Wayland security.
- **Screen sharing — eski Zoom** — PipeWire portal yoki Xwayland fallback.
- **NVIDIA + Sway** — driver muammosi. Modeset ihtiyot.
- **`DISPLAY=:0` o'rniga `WAYLAND_DISPLAY`** — Wayland env o'zgaruvchi.
- **Eski Electron ilovalar** — `--enable-features=UseOzonePlatform --ozone-platform=wayland` flag.

## 16. Eng yaxshi amaliyot

- **Modern desktop — Wayland.** Ko'p afzalliklar.
- **Eski app'lar uchun Xwayland avtomatik** — ko'p hollarda muammosiz.
- **Firefox/Chrome wayland flag** — performance va smooth scrolling.
- **NVIDIA — GNOME bilan** (driver eng yaxshi qo'llab-quvvatlash).
- **AMD/Intel — har joyda** — open-source drayver standart.
- **i3'dan kelganlar — Sway.** Aksincha — eski Wayfire/Cosmic.
- **PipeWire + portal** screen sharing uchun.
