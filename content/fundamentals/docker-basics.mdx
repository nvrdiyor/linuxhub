**Docker** — dasturlarni **container**'larda paketlash va ishga tushirish platformasi. Container — yengil, izolyatsiyalangan jarayon — VM'dan ancha kichik, lekin shunga o'xshash xavfsizlik darajasi.[¹](https://docs.docker.com/)

<Callout type="info" title="Bu darsda nimani o'rganasiz">
- Docker asoslari va terminologiya.
- Image va container farqi.
- Asosiy buyruqlar: run, ps, exec, logs.
- Dockerfile yozish.
- docker compose bilan multi-container ilovalar.
</Callout>

## 1. Container vs VM

```
VM:                          Container:
┌─────────────┐              ┌──────────────┐
│ App         │              │ App          │
│ Libs        │              │ Libs         │
│ Guest OS    │              │              │
│ Hypervisor  │              │  Docker      │
│ Host OS     │              │  Host OS     │
└─────────────┘              └──────────────┘
~1 GB+                       ~10 MB+
Yuklanish sekin               Sekundsiz boshlash
Apparat virtualizatsiya       Yadro umumiy
```

Container'lar:

- Yadroni **host bilan baham ko'radi** (alohida emas).
- Process isolation, namespace, cgroup orqali xavfsizlik.
- 100-1000x VM'dan tezroq boshlanadi.
- Kichikroq image hajmi.

## 2. Docker o'rnatish

```bash
# Debian/Ubuntu (rasmiy repo)
sudo apt update
sudo apt install ca-certificates curl gnupg

# Docker GPG key va repo
sudo install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg

echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.gpg] https://download.docker.com/linux/ubuntu $(lsb_release -cs) stable" | sudo tee /etc/apt/sources.list.d/docker.list

sudo apt update
sudo apt install docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin

# Foydalanuvchi'ni docker guruhiga (root'siz)
sudo usermod -aG docker $USER

# Logout/login, so'ng test
docker run hello-world
```

## 3. Image va Container

**Image** — shabloncha (read-only). Misol: `ubuntu:22.04`, `nginx:latest`, `postgres:15`.

**Container** — image'dan yaratilgan ishga tushirilgan instance.

```
Image (template)  →  Container (running instance)
```

Bir image'dan **ko'p container** yaratish mumkin.

## 4. Asosiy buyruqlar

```bash
# Image'ni Docker Hub'dan yuklab olish
docker pull nginx

# Image'lar ro'yxati
docker images
# yoki
docker image ls

# Container ishga tushirish
docker run nginx
# Foreground — Ctrl+C bilan to'xtatish

# Background (`-d` detached)
docker run -d nginx

# Nom bilan (`--name`)
docker run -d --name my-nginx nginx

# Port mapping (`-p host:container`)
docker run -d -p 8080:80 --name web nginx
# Endi http://localhost:8080 ishlaydi

# Volume mount (`-v host:container`)
docker run -d -v /var/www:/usr/share/nginx/html -p 80:80 nginx

# Environment o'zgaruvchilar (`-e`)
docker run -d -e POSTGRES_PASSWORD=secret postgres
```

## 5. Container holatini boshqarish

```bash
# Ishlamoqda
docker ps

# Hamma (jumladan to'xtagan)
docker ps -a

# To'xtatish
docker stop my-nginx

# Boshlash
docker start my-nginx

# Restart
docker restart my-nginx

# Pause/unpause
docker pause my-nginx
docker unpause my-nginx

# O'chirish (avval to'xtatilgan bo'lishi kerak)
docker rm my-nginx

# Majburiy o'chirish (running)
docker rm -f my-nginx
```

## 6. Container ichiga kirish

```bash
# Mavjud container ichida buyruq
docker exec my-nginx ls /etc/nginx

# Interaktiv shell
docker exec -it my-nginx bash
# yoki sh (Alpine kabi minimal image'larda)
docker exec -it my-nginx sh
```

## 7. Loglar

```bash
# Container loglari
docker logs my-nginx

# Real-time (tail -f kabi)
docker logs -f my-nginx

# Oxirgi N qator
docker logs --tail 100 my-nginx

# Vaqt bilan
docker logs --since 1h my-nginx
```

## 8. Image yaratish — Dockerfile

`Dockerfile` — image yaratish ko'rsatmalari.

```dockerfile
# Asos image
FROM ubuntu:22.04

# Metadata
LABEL maintainer="alice@example.com"

# Paket o'rnatish
RUN apt-get update && apt-get install -y \
    python3 \
    python3-pip \
    && rm -rf /var/lib/apt/lists/*

# Ish katalogi
WORKDIR /app

# Fayl nusxalash
COPY requirements.txt .
RUN pip3 install -r requirements.txt

COPY . .

# Port
EXPOSE 5000

# Container yoqilganda bajarilish
CMD ["python3", "app.py"]
```

### Build

```bash
# Joriy katalogdagi Dockerfile
docker build -t myapp:1.0 .

# Image ro'yxatida
docker images

# Run
docker run -d -p 5000:5000 myapp:1.0
```

## 9. Dockerfile direktivalari

| Direktiv | Maqsad |
|---|---|
| `FROM` | Asos image |
| `RUN` | Build vaqtida buyruq |
| `COPY` | Fayl/katalog nusxalash |
| `ADD` | COPY + URL/archive ochish |
| `WORKDIR` | Ish katalog |
| `ENV` | Muhit o'zgaruvchisi |
| `EXPOSE` | Port hujjat (metadata, tarmoq emas) |
| `CMD` | Default buyruq (override mumkin) |
| `ENTRYPOINT` | Doim bajariladigan |
| `VOLUME` | Volume mountpoint |
| `USER` | Foydalanuvchi (root'siz) |
| `ARG` | Build-time argument |

## 10. Image optimizatsiya

```dockerfile
# YOMON — har RUN yangi layer
FROM ubuntu:22.04
RUN apt-get update
RUN apt-get install -y python3
RUN apt-get install -y pip
RUN apt-get clean

# YAXSHI — bitta layer
FROM ubuntu:22.04
RUN apt-get update && \
    apt-get install -y python3 pip && \
    apt-get clean && \
    rm -rf /var/lib/apt/lists/*
```

### Multi-stage build

```dockerfile
# Stage 1 — build
FROM node:20 AS builder
WORKDIR /app
COPY package.json .
RUN npm install
COPY . .
RUN npm run build

# Stage 2 — runtime (kichik)
FROM nginx:alpine
COPY --from=builder /app/dist /usr/share/nginx/html
```

Natija — runtime image faqat nginx + build fayllari, build tools yo'q.

### Image hajmi

```bash
docker images
# REPOSITORY   TAG       SIZE
# myapp        1.0       150MB
# nginx        alpine    23MB        ← juda kichik
```

Tavsiya: `alpine` yoki `distroless` asos image'lar.

## 11. Volume va data persistence

Container o'chirilganda ichidagi ma'lumot yo'qoladi (default). Volume — persistent storage.

```bash
# Named volume yaratish
docker volume create mydata

# Container'ga mount
docker run -d -v mydata:/var/lib/mysql mysql

# Volume'lar ro'yxati
docker volume ls

# Volume ma'lumotlari
docker volume inspect mydata

# O'chirish
docker volume rm mydata
```

### Bind mount (host katalogi)

```bash
# Host'ning aniq katalogini mount
docker run -d -v /home/alice/data:/data myapp

# Yoki
docker run -d --mount type=bind,source=/home/alice/data,target=/data myapp
```

| Tur | Qachon |
|---|---|
| `volume` (named) | Docker boshqaradi, ko'chirish oson |
| `bind` mount | Host'ga to'g'ridan-to'g'ri |
| `tmpfs` | RAM'da (vaqtinchalik, tez) |

## 12. Tarmoq

Container'lar default'da `bridge` tarmoqda — bir-biri bilan ulanishi mumkin (lekin nomdan oson emas).

```bash
# Custom bridge — nomdan ulanish
docker network create mynet

docker run -d --name db --network mynet postgres
docker run -d --name app --network mynet -e DATABASE_URL=postgres://db/myapp myapp

# Endi 'app' container'da 'db' DNS orqali ko'rinadi
```

Tarmoq turlari:

| Tur | Maqsad |
|---|---|
| `bridge` (default) | Lokal Docker network |
| `host` | Host tarmog'i (port mapping yo'q) |
| `none` | Tarmoqsiz |
| `overlay` | Multi-host (Swarm) |

## 13. docker compose — multi-container

`compose.yml` (yoki `docker-compose.yml`) — bir nechta container birga:

```yaml
version: '3.9'

services:
  db:
    image: postgres:15
    restart: always
    environment:
      POSTGRES_PASSWORD: secret
      POSTGRES_DB: myapp
    volumes:
      - db-data:/var/lib/postgresql/data

  web:
    build: .
    restart: always
    ports:
      - "8080:5000"
    environment:
      DATABASE_URL: postgres://postgres:secret@db:5432/myapp
    depends_on:
      - db
    volumes:
      - ./app:/app

  nginx:
    image: nginx:alpine
    restart: always
    ports:
      - "80:80"
    volumes:
      - ./nginx.conf:/etc/nginx/nginx.conf:ro
    depends_on:
      - web

volumes:
  db-data:
```

### Compose buyruqlar

```bash
# Hammasini ishga tushirish
docker compose up -d

# To'xtatish va o'chirish
docker compose down

# Loglar
docker compose logs -f

# Faqat aniq xizmat
docker compose logs web

# Restart
docker compose restart web

# Build (Dockerfile o'zgartirilsa)
docker compose build
docker compose up -d --build

# Scale (bir nechta instance)
docker compose up -d --scale web=3
```

## 14. Image registry — push/pull

```bash
# Docker Hub'ga login
docker login

# Tag (yangi nom bilan)
docker tag myapp:1.0 myusername/myapp:1.0

# Push
docker push myusername/myapp:1.0

# Boshqa joydan pull
docker pull myusername/myapp:1.0
```

Private registry: GitHub Container Registry, GitLab Container Registry, AWS ECR va boshqalar.

## 15. Resurs cheklash

```bash

# Yoki compose
services:
  web:
    image: nginx

        limits:

```

## 17. Eng tez-tez uchraydigan xatolar

- **Port konflikt** — `bind: address already in use`. Boshqa container yoki dastur shu portda. `docker ps` yoki `ss -tnlp`.
- **Container darrov tugaydi** — `CMD` yoki `ENTRYPOINT` ishlamayapti. `docker logs <name>` orqali sabab.
- **Permission denied volume'da** — Container ichidagi UID host UID bilan mos kelmaydi.
- **Build cache stale** — `--no-cache` flag bilan.
- **`docker rm` ishlamaydi — container ishlamoqda** — avval `docker stop`.
- **Disk to'lib qoldi** — `docker system prune -a` tozalaydi (lekin diqqat — image va volume'lar yo'qoladi).

## 18. Eng yaxshi amaliyot

- **Eng kichik base image** — `alpine`, `distroless`.
- **Multi-stage build** — runtime image kichikroq.
- **`.dockerignore`** — `node_modules`, `.git` build'ga kirmasligi uchun.
- **Bitta jarayon — bitta container.**
- **`USER`** non-root — xavfsizlik.
- **Tag — `latest` o'rniga aniq versiya** — reproducibility.
- **Volume named bilan** — backup va ko'chirish oson.
- **Compose production'da ham** — bir nechta xizmat uchun.
- **Logs `json-file` rotation** — disk to'lib qolish'dan.
- **Health checks** — `HEALTHCHECK` Dockerfile'da.

## 19. Mashqlar

1. **Birinchi container:** `docker run hello-world` — ishlatadimi?
2. **Nginx:** `docker run -d -p 8080:80 --name web nginx`. `curl http://localhost:8080`.
3. **Loglar:** `docker logs -f web` ni alohida terminal'da kuzating. Brauzer'da saytni oching.
4. **Exec:** `docker exec -it web bash` — container ichiga kirib `cat /etc/nginx/nginx.conf` ni ko'ring.
5. **Dockerfile:** Oddiy Python skript uchun Dockerfile yozing va build qiling.
6. **Compose:** Yuqoridagi 3-xizmat (db + web + nginx) compose.yml bilan ishga tushiring.
