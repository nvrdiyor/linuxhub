# Linux nima?

Linux — bu butun dunyo bo'ylab millionlab kompyuterlar, serverlar, smartfonlar va hatto kosmik kemalarni boshqaruvchi **ochiq kodli operatsion tizim yadrosi** (kernel). Lekin ko'pchilik "Linux" deganda nafaqat yadroni, balki to'liq operatsion tizimni nazarda tutadi.

## Kernel va Operatsion Tizim farqi

**Kernel (yadro)** — bu kompyuter uskunasi (hardware) bilan dasturlar o'rtasidagi ko'prik. U quyidagi vazifalarni bajaradi:

- 💾 Xotira boshqaruvi
- ⚡ Protsessor vaqtini taqsimlash
- 🔌 Qurilmalar bilan aloqa
- 📁 Fayl tizimlarini boshqarish

**Operatsion tizim** esa kerneldan tashqari quyidagilarni o'z ichiga oladi:
- Grafik interfeys (GUI)
- Tizim ilovalari
- Paket menejeri
- Foydalanuvchi asboblari

> Linux — bu kernel. Ubuntu, Fedora, NixOS — bu kerneldan foydalanuvchi to'liq **distributivlar**.

- 🌐 Internet serverlarining 96%+ da ishlaydi
- 📱 Android telefonlarining barchasida
- ☁️ Bulutli xizmatlarning aksariyatida
- 🚀 SpaceX va NASA missiyalarida

## Ochiq kodli falsafa

Linux **ochiq kodli** (open source) lisenziya ostida tarqatiladi. Bu nimani anglatadi?

1. **Kod ochiq** — har kim kodni ko'rishi mumkin
2. **Bepul** — sotib olish shart emas
3. **Erkin** — o'zgartirish va tarqatish mumkin
4. **Hamjamiyat** — minglab dasturchilar birgalikda rivojlantiradi

```bash
# Linux kernelining versiyasini ko'rish
uname -r

# Tizim haqida to'liq ma'lumot
cat /etc/os-release
```

## Nega Linux o'rganish kerak?

### Dasturchilar uchun
- Ko'pchilik serverlar Linuxda ishlaydi
- DevOps va Cloud texnologiyalar Linux asosida
- Open source loyihalar odatda Linuxda rivojlanadi

### Oddiy foydalanuvchilar uchun
- Butunlay bepul
- Viruslar kamroq
- Eski kompyuterlarda ham tez ishlaydi
- Maxfiylik va xavfsizlik

### IT mutaxassislari uchun
- Tizimni to'liq nazorat qilish
- Avtomatlashtirish imkoniyatlari
- Professional asboblar to'plami
