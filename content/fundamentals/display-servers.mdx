# Display Serverlar: X11 vs Wayland

Display server — bu dasturlar va grafik qurilmalar o'rtasidagi ko'prik. U oynalarni chizish, klaviatura/sichqoncha kiritishlarini boshqarish uchun javobgar.

### X11 xususiyatlari

| Xususiyat | Qiymati |
|-----------|---------|
| Yoshi | 40+ yil |
| Orqaga moslik | ⭐⭐⭐⭐⭐ |
| Xavfsizlik | ⭐⭐ (Har qanday dastur boshqasini "ko'ra" oladi) |

</Callout>

## To'g'ridan-to'g'ri solishtiruv

| Xususiyat | X11 | Wayland |
|-----------|-----|---------|
| **Arxitektura** | Client-Server (ajratilgan) | Kompozitor (birlashgan) |
| **Xavfsizlik** | 🔓 Zaif (dasturlar bir-birini ko'radi) | 🔒 Kuchli (izolyatsiya) |
| **Ishlash tezligi** | Yaxshi | Juda yaxshi |
| **Screen recording** | Oson | Murakkab (portal orqali) |
| **Nvidia qo'llab-quvvatlashi** | ⭐⭐⭐⭐⭐ | ⭐⭐⭐⭐ (Yaxshilanmoqda) |
| **Eski dasturlar** | ⭐⭐⭐⭐⭐ | XWayland orqali |
| **Kelajak** | Legacy | Standart |

## Compositor'lar (Wayland)

Wayland'da compositor display server vazifasini ham bajaradi:

### Desktop Environment compositor'lari

| DE | Compositor | Holati |
|----|------------|--------|
| GNOME | Mutter | ✅ Stabil |
| KDE | KWin | ✅ Stabil |
| XFCE | - | 🔄 Ishlanmoqda |

### Window Manager compositor'lari

| WM | Turi | Xususiyati |
|----|------|------------|
| **Hyprland** | Tiling | Animatsiyalar, zamonaviy |
| **Sway** | Tiling | i3 bilan mos |
| **Weston** | Stacking | Reference implementation |
| **River** | Tiling | Sodda, tez |

## Qaysi birini tanlash kerak?

```
Siz tanlang:

🟢 Wayland — agar:
   • Yangi kompyuter/laptop
   • Xavfsizlik muhim
   • GNOME/KDE ishlatmoqchisiz
   • Nvidia RTX 20+ kartangiz bor

🟡 X11 — agar:
   • Eski hardware
   • SSH X forwarding kerak
   • Nvidia eski karta
   • Maxsus dasturlar (ba'zi CAD)
```

<Callout type="tip">
**Tavsiya:** Yangi o'rnatishlar uchun Wayland'ni sinab ko'ring. Muammo chiqsa, X11'ga o'tish oson.
</Callout>
