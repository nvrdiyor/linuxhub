# Linux Distributivlari Shajarasi

Linux dunyosida yuzlab turli **distributivlar** mavjud. Har biri Linux kernelidan foydalanadi, lekin turli maqsadlar va foydalanuvchilar uchun moslashtirilgan.

Quyida asosiy oilalarni interaktiv tarzda ko'rishingiz mumkin:

<LinuxFamilyTree />

## Asosiy oilalar haqida batafsil

### 🔵 Debian oilasi

**Xususiyatlari:**
- Barqarorlik va ishonchlilik
- APT paket menejeri
- `.deb` paket formati
- Keng hamjamiyat qo'llab-quvvatlashi

| Distributiv | Maqsad |
|-------------|--------|
| **Debian** | Server va barqaror ish stoli |
| **Ubuntu** | Boshlang'ich foydalanuvchilar uchun eng qulay |
| **Linux Mint** | Windows'dan o'tuvchilar uchun |
| **Kali Linux** | Xavfsizlik testlari |
| **Pop!_OS** | Dasturchilar va o'yinchilar |

```bash
# Debian oilasida paket o'rnatish
sudo apt update
sudo apt install paket-nomi
```

---

### 🟢 Arch oilasi

**Xususiyatlari:**
- "Bleeding edge" — eng yangi versiyalar
- Rolling release model
- Pacman paket menejeri
- Minimalizm va moslashuvchanlik

| Distributiv | Maqsad |
|-------------|--------|
| **Arch Linux** | Tajribali foydalanuvchilar, DIY |
| **Manjaro** | Arch'ning qulay versiyasi |
| **EndeavourOS** | Arch'ga oson kirish |

```bash
# Arch oilasida paket o'rnatish
sudo pacman -S paket-nomi

# AUR dan o'rnatish
yay -S aur-paket
```

---

### 🔴 Red Hat oilasi

**Xususiyatlari:**
- Korporativ va server maqsadlar
- DNF/YUM paket menejeri
- `.rpm` paket formati
- Tijorat qo'llab-quvvatlash mavjud

| Distributiv | Maqsad |
|-------------|--------|
| **RHEL** | Korporativ serverlar |
| **Fedora** | Yangi texnologiyalarni sinash |
| **CentOS/Rocky** | RHEL ning bepul alternativasi |
| **AlmaLinux** | RHEL bilan mos server OS |

```bash
# Red Hat oilasida paket o'rnatish
sudo dnf install paket-nomi
```

---

### 🟣 Mustaqil distributivlar

Ba'zi distributivlar boshqalardan kelib chiqmagan — ular o'ziga xos yondashuv bilan yaratilgan:

| Distributiv | O'ziga xosligi |
|-------------|----------------|
| **NixOS** | Deklarativ konfiguratsiya, takrorlanadigan tizim |
| **Void Linux** | runit init tizimi, soddalik |
| **Gentoo** | Source-based, maksimal optimallashtirish |
| **Slackware** | Eng qadimiy distributivlardan biri |

## Qaysi birini tanlash kerak?

| Holat | Tavsiya |
|-------|---------|
| Yangi boshlovchi | Ubuntu yoki Linux Mint |
| O'rganishni xohlayman | Manjaro yoki Fedora |
| Server uchun | Debian yoki Rocky Linux |
| Xavfsizlik | Kali yoki Parrot |
| Zamonaviy yondashuv | NixOS |
