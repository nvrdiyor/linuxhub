## 1. `auditd` — security audit

**auditd** — Linux Audit System. Kim, qachon, nima qildi — yozib boradi.

```bash
# O'rnatish
sudo apt install auditd

# Yoqish
sudo systemctl enable --now auditd
```

### Qoidalar — `/etc/audit/rules.d/`

`/etc/audit/rules.d/01-base.rules`:

```
# Sensitive fayl'larni kuzatish
-w /etc/passwd -p wa -k passwd_changes
-w /etc/shadow -p wa -k shadow_changes
-w /etc/sudoers -p wa -k sudoers_changes
-w /etc/ssh/sshd_config -p wa -k sshd_changes

# Sudo'ni kuzatish
-a always,exit -F arch=b64 -S execve -F euid=0 -k sudo_use

# User va group o'zgarishi
-w /usr/sbin/useradd -p x -k user_modification
-w /usr/sbin/usermod -p x -k user_modification
-w /usr/sbin/userdel -p x -k user_modification

# `passwd` ishlatilishi
-w /usr/bin/passwd -p x -k passwd_use

# Setuid binary'lar (potentially privilege escalation)
-a always,exit -F arch=b64 -S setuid -k setuid_calls
-a always,exit -F arch=b64 -S setgid -k setgid_calls
```

`-w` — file watch:
- `-p` permissions: `w` write, `r` read, `x` execute, `a` attribute change.
- `-k` — key (qidirish uchun).

`-a always,exit` — syscall audit:
- `arch=b64` — 64-bit.
- `-S execve` — syscall nomi.

```bash
# Qoidalar yuklash
sudo augenrules --load

# Joriy qoidalar
sudo auditctl -l
```

## 2. Audit log'larni qidirish

```bash
# Real-time
sudo tail -f /var/log/audit/audit.log

# Aniq key bo'yicha
sudo ausearch -k sudo_use

# Vaqt bilan
sudo ausearch -k passwd_changes --start today

# Aniq user
sudo ausearch -ua ali

# Aniq sana oraliq
sudo ausearch --start 2026-05-26 --end 2026-05-27
```

## 4. Prometheus — modern metrics

**Prometheus** — time-series database va monitoring system. Pull model — server klient'larga so'rov yuboradi.

### O'rnatish

```bash
# Binary yuklab olish
wget https://github.com/prometheus/prometheus/releases/download/v2.50.0/prometheus-2.50.0.linux-amd64.tar.gz
tar xzf prometheus-2.50.0.linux-amd64.tar.gz
sudo mv prometheus-2.50.0.linux-amd64 /opt/prometheus

# Yoki repository
sudo apt install prometheus
```

`/etc/prometheus/prometheus.yml`:

```yaml
global:
  scrape_interval: 15s

scrape_configs:
  - job_name: 'prometheus'
    static_configs:
      - targets: ['localhost:9090']

  - job_name: 'node'
    static_configs:
      - targets: ['localhost:9100']

  - job_name: 'nginx'
    static_configs:
      - targets: ['localhost:9113']
```

```bash
sudo systemctl restart prometheus
# UI: http://localhost:9090
```

## 5. Node Exporter

Node Exporter — Prometheus uchun system metrikalar (CPU, RAM, disk, tarmoq).

```bash
# O'rnatish
sudo apt install prometheus-node-exporter

# Default port 9100
sudo systemctl enable --now prometheus-node-exporter

# Test
curl http://localhost:9100/metrics
```

Prometheus avtomatik scrape qiladi.

### Foydali metrikalar

- `node_cpu_seconds_total` — CPU
- `node_memory_MemAvailable_bytes` — bo'sh RAM
- `node_filesystem_avail_bytes` — disk
- `node_network_receive_bytes_total` — tarmoq

## 6. Prometheus query — PromQL

```promql
# RAM ishlatish
100 - (node_memory_MemAvailable_bytes / node_memory_MemTotal_bytes * 100)

# CPU foiz
100 - (avg by(instance) (irate(node_cpu_seconds_total{mode="idle"}[5m])) * 100)

# Disk band
100 - ((node_filesystem_avail_bytes / node_filesystem_size_bytes) * 100)

# Network in/out
rate(node_network_receive_bytes_total[5m])
rate(node_network_transmit_bytes_total[5m])
```

## 7. Grafana — visualization

**Grafana** — Prometheus (va boshqa) data source'lardan dashboard.


3. Dashboard avtomatik to'liq sozlangan grafiklar bilan.

## 8. Alerting — `Alertmanager`

Prometheus'ning alert komponenti.

```bash
sudo apt install prometheus-alertmanager
```

`/etc/prometheus/alerts.yml`:

```yaml
groups:
  - name: system
    interval: 30s
    rules:
      - alert: HighMemory
        expr: (node_memory_MemAvailable_bytes / node_memory_MemTotal_bytes) * 100 < 10
        for: 5m
        labels:
          severity: warning
        annotations:
          summary: "High memory on {{ $labels.instance }}"
          description: "Available memory is {{ $value }}%"

      - alert: DiskFull
        expr: (node_filesystem_avail_bytes / node_filesystem_size_bytes) * 100 < 10
        for: 5m
        labels:
          severity: critical
        annotations:
          summary: "Disk almost full on {{ $labels.instance }}"
```

`/etc/prometheus/alertmanager.yml`:

```yaml
route:
  receiver: 'email'

receivers:
  - name: 'email'
    email_configs:
      - to: 'admin@example.com'
        from: 'alerts@example.com'
        smarthost: 'smtp.gmail.com:587'
        auth_username: 'alerts@example.com'
        auth_password: 'apppassword'
```

Yoki Telegram, Slack, PagerDuty.

## 11. Misol — to'liq monitoring stack

```yaml
# docker-compose.yml
version: '3.8'

services:
  prometheus:
    image: prom/prometheus
    ports:
      - "9090:9090"
    volumes:
      - ./prometheus.yml:/etc/prometheus/prometheus.yml
      - prom-data:/prometheus

  node-exporter:
    image: prom/node-exporter
    ports:
      - "9100:9100"
    pid: host
    volumes:
      - /:/host:ro,rslave

  grafana:
    image: grafana/grafana
    ports:
      - "3000:3000"
    environment:
      - GF_SECURITY_ADMIN_PASSWORD=admin
    volumes:
      - grafana-data:/var/lib/grafana

  alertmanager:
    image: prom/alertmanager
    ports:
      - "9093:9093"
    volumes:
      - ./alertmanager.yml:/etc/alertmanager/alertmanager.yml

volumes:
  prom-data:
  grafana-data:
```

```bash
docker compose up -d
```

## 13. Eng tez-tez uchraydigan xatolar

- **auditd disk to'ldirib qo'yadi** — `max_log_file = 50` `/etc/audit/auditd.conf`.
- **Prometheus retention 15 kun (default)** — kattaroq saqlash uchun `--storage.tsdb.retention.time=30d`.
- **Grafana password unutish** — `/etc/grafana/grafana.ini` reset.
- **Node Exporter container'da** — `--pid host` va `/proc`, `/sys` mount kerak.
- **Alerts spam** — `for: 5m` (transient muammolarni filtrlash).

## 14. Eng yaxshi amaliyot

- **auditd security uchun production'da** — har serverda.
- **Prometheus + Grafana** — long-term metrics.
- **Netdata** — boshlovchilar uchun yoki one-off server uchun.
- **Markazlashtirilgan logging** (Loki, ELK).
- **Alert "noise" dan saqlanish** — kerakli alarmlar.
- **PagerDuty / OpsGenie** — incident response.
- **Runbook'lar** — har alert uchun nima qilish ko'rsatma.
- **SLO/SLI** — service level objectives.

## 15. Mashqlar

1. **auditd:** O'rnatib `/etc/passwd` watch qo'shing. `passwd` o'zgartirish'dan keyin `ausearch -k passwd_changes`.

3. **Prometheus:** Docker'da ishga tushiring. UI'ga kirib `up` query qiling.
4. **Grafana:** O'rnatib Node Exporter dashboard import qiling (ID 1860).
5. **Netdata:** O'rnating va UI'ni o'rganing.
6. **Alert:** Test alert yarating (disk usage > 80%).
