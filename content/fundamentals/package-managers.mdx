# Paket menejerlari

Windows'da dastur o'rnatish uchun `.exe` faylni yuklab, "Next, Next, Finish" bosasiz. Linux'da esa **paket menejerlari** orqali bir buyruq bilan minglab dasturlarni o'rnatish mumkin!

## Paket menejeri nima?

Paket menejeri — bu:
- 📦 Dasturlarni yuklab olish
- 🔧 To'g'ri joylarga o'rnatish
- 🔄 Yangilashlarni boshqarish
- 🗑️ Kerak bo'lmaganda o'chirish

Bularni hammasi **bitta buyruq** bilan!

## Asosiy paket menejerlari

### 🔵 APT (Debian/Ubuntu oilasi)

Eng mashhur va qulay paket menejeri:

```bash
# Paketlar ro'yxatini yangilash
sudo apt update

# Barcha dasturlarni yangilash
sudo apt upgrade

# Dastur o'rnatish
sudo apt install firefox

# Dastur o'chirish
sudo apt remove firefox

# Dasturni qidirish
apt search video-player
```

### 🟢 Pacman (Arch oilasi)

Tez va sodda paket menejeri:

```bash
# Tizimni yangilash
sudo pacman -Syu

# Dastur o'rnatish
sudo pacman -S firefox

# Dastur o'chirish
sudo pacman -R firefox

# Qidirish
pacman -Ss video
```

**AUR yordamchilari** (rasmiy bo'lmagan paketlar uchun):
```bash
# yay orqali AUR dan o'rnatish
yay -S spotify
```

### 🔴 DNF (Fedora/RHEL oilasi)

```bash
# Tizimni yangilash
sudo dnf upgrade

# Dastur o'rnatish
sudo dnf install firefox

# Dastur o'chirish
sudo dnf remove firefox

# Qidirish
dnf search video
```

## Buyruqlar solishtirmasi

| Vazifa | APT (Debian) | Pacman (Arch) | DNF (Fedora) |
|--------|--------------|---------------|--------------|
| Paket bazasini yangilash | `apt update` | (`pacman -Syu` ichida) | `dnf check-update` |
| Yangilash (full upgrade) | `apt upgrade` | `pacman -Syu` | `dnf upgrade` |
| O'rnatish | `apt install X` | `pacman -S X` | `dnf install X` |
| O'chirish | `apt remove X` | `pacman -R X` | `dnf remove X` |
| Qidirish | `apt search X` | `pacman -Ss X` | `dnf search X` |

<Callout type="warning" title="Pacman uchun muhim ogohlantirish">
Arch va Manjaro tizimlarida **hech qachon faqat `pacman -Sy` ishlatmang** — bu paket ma'lumotlar bazasini yangilaydi, lekin paketlarni yangilamaydi va shu sababli "qisman yangilash" holatiga olib keladi. Bu Arch tomonidan rasmiy ravishda qo'llab-quvvatlanmaydi — manba: [ArchWiki: System maintenance — Partial upgrades are unsupported](https://wiki.archlinux.org/title/System_maintenance#Partial_upgrades_are_unsupported). Har doim `pacman -Syu` ishlating.
</Callout>

## "sudo" nima?

`sudo` — "superuser do" degan ma'noni anglatadi. Tizim darajasidagi o'zgarishlar uchun administrator huquqlari kerak:

```bash
# Xato — ruxsat berilmaydi
apt install firefox

# To'g'ri — administrator sifatida
sudo apt install firefox
```

> 💡 `sudo` sizdan parolni so'raydi. Parolni yozayotganingizda ekranda hech narsa ko'rinmaydi — bu normal!

## Universal paket formatlar

Ba'zi dasturlar barcha distributivlarda ishlaydi:

### Flatpak
```bash
# Flatpak o'rnatish
sudo apt install flatpak

# Dastur o'rnatish
flatpak install spotify
```

### Snap (Ubuntu)
```bash
# Snap orqali o'rnatish
sudo snap install spotify
```

### AppImage
- Yuklab oling
- Bajariladigan qiling: `chmod +x dastur.AppImage`
- Ishga tushiring: `./dastur.AppImage`

## Amaliy misol

Keling, VLC media player o'rnatamiz:

**Ubuntu/Debian:**
```bash
sudo apt update
sudo apt install vlc
```

**Manjaro/Arch:**
```bash
sudo pacman -S vlc
```

**Fedora:**
```bash
sudo dnf install vlc
```

## Xavfsizlik haqida

⚠️ **Ehtiyot bo'ling:**
- Faqat rasmiy repozitoriylardan o'rnating
- Internetdan `.deb` yoki `.rpm` yuklamasdan avval tekshiring
- `sudo` ni har doim sinchiklab ishlating
