# Parrot OS ga xush kelibsiz! 🦜

**Parrot OS** — bu xavfsizlik, rivojlantirish va maxfiylik uchun mo'ljallangan ko'p qirrali Linux distributivi.

## Parrot OS nima?

Parrot OS Debian Testing asosida qurilgan va uch asosiy maqsadga xizmat qiladi:

1. **Xavfsizlik va pentesting**
2. **Dasturiy ta'minot ishlab chiqish**
3. **Maxfiylik va anonimlik**

<Callout type="info">
  Parrot OS Kali Linux ga alternativa sifatida ko'riladi, lekin u kundalik foydalanish uchun ham mos.
</Callout>

## Versiyalar

| Versiya | Maqsad |
|---------|--------|
| **Security Edition** | Pentesting va xavfsizlik auditi |
| **Home Edition** | Kundalik foydalanish va maxfiylik |
| **Architect Edition** | Minimal o'rnatish, o'zingiz sozlaysiz |

## Afzalliklari

<Steps>
  <Step title="Yengil va tezkor">
    Kam resurs talab qiladi, eski kompyuterlarda ham ishlaydi
  </Step>
  <Step title="Maxfiylik vositalari">
    Tor, Anonsurf va boshqa anonimlik vositalari o'rnatilgan
  </Step>
  <Step title="Rivojlantirish uchun">
    Ko'plab dasturlash tillari va IDE lar mavjud
  </Step>
</Steps>

## Terminal misoli

```bash
# Parrot tizimini yangilash
sudo parrot-upgrade

# Anonsurf ni yoqish
sudo anonsurf start

# Statusni tekshirish
anonsurf status
```

<Callout type="tip">
  `anonsurf` yordamida barcha internet trafigingiz Tor orqali yo'naltiriladi.
</Callout>
