<Callout type="warning" title="Anonimlik mas'uliyat bilan">
Tor — qonuniy texnologiya. Lekin uni jinoiy faoliyat uchun ishlatish — qonun bo'yicha jinoiy javobgarlik. Tor sizni "ko'rinmas" qilmaydi — texnik xatolar yoki ehtiyotsizlik orqali aniqlanishingiz mumkin.
</Callout>

**Tor** (The Onion Router) — anonimlikni ta'minlovchi tarmoq. Trafik ko'ngilli relaylar zanjiri orqali shifrlangan o'tadi. Parrot OS'da Tor va **AnonSurf** (butun tizim trafigini Tor orqali yuborish) integratsiya qilingan.[¹](https://www.torproject.org/about/history/)

<Callout type="info" title="Bu darsda nimani o'rganasiz">
- Tor qanday ishlaydi.
- Tor Browser bilan ishlash.
- AnonSurf — butun trafikni Tor'ga.
- Anonimlik chegaralari.
</Callout>

## 1. Tor qanday ishlaydi?

```
Siz ──▶ Guard Relay ──▶ Middle Relay ──▶ Exit Relay ──▶ Sayt
        (kirish)         (oraliq)         (chiqish)
```

- Har bir relay faqat **bir oldingi** va **bir keyingi** xostni biladi.
- Trafik **uch qatlamli shifrlangan** — har relay o'z qatlamini ochadi.
- Exit relay sizning haqiqiy IP'ngizni bilmaydi.
- Sayt esa faqat Exit relay IP'sini ko'radi.

Bu "onion routing" — har qatlam piyozning po'sti kabi.

## 2. Tor Browser

Tor Browser — eng oson va eng xavfsiz Tor'dan foydalanish usuli. U Firefox asosida, lekin maxsus sozlangan (JavaScript cheklangan, fingerprinting kamaytirilgan).

```bash
# Parrot'da default keladi yoki o'rnatish
sudo apt install torbrowser-launcher

# Ishga tushirish
torbrowser-launcher
```

Birinchi marotaba Tor Browser'ni rasmiy saytdan yuklab oladi va imzosini tekshiradi.

**Foydalanish:**

- Faqat Tor Browser ichidagi trafik Tor orqali.
- Boshqa brauzer (Firefox, Chrome) odatiy ulanadi.
- HTTPS doim ishlatilsin (Exit relay HTTP'ni o'qiy oladi).

## 3. AnonSurf — butun tizim trafigi Tor orqali

AnonSurf Parrot OS'ga xos vosita.[³](https://docs.parrotsec.org/anonymity/) Butun tizim trafigini (Firefox, terminal, ilovalar) Tor'ga yo'naltiradi.

```bash
# Statusni ko'rish
anonsurf status

# Yoqish
sudo anonsurf start

# To'xtatish
sudo anonsurf stop

# Tor identity'ni o'zgartirish (yangi zanjir)
sudo anonsurf change

# IP tekshirish (Tor orqalimi?)
anonsurf myip
```

**Yoqilgan holatda:**

- Hamma trafik Tor orqali.
- DNS so'rovlari ham Tor orqali (DNS leak yo'q).
- IP `anonsurf myip` orqali tekshiriladi — bu real IP emas, balki Exit relay IP'si bo'lishi kerak.

## 4. Tekshirish

Brauzer orqali [https://check.torproject.org](https://check.torproject.org/) ga kiring:

> "Congratulations. This browser is configured to use Tor."

Yoki:

```bash
curl -s https://check.torproject.org/api/ip | python3 -m json.tool
```

## 5. Anonimlik chegaralari

Tor sizni **ko'rinmas qilmaydi**. Quyidagilar siz tomondan keladigan xavf:

### 1. Login

Agar siz Tor orqali Gmail'ga kirsangiz, Google sizning haqiqiy identifikatingizni biladi. Tor IP'ni yashiradi, lekin **siz** — emas.

### 2. Browser fingerprinting

Brauzer versiyasi, ekran o'lchami, plugin'lar — bularning kombinatsiyasi sizni unique qiladi. Tor Browser bu omilni minimallashtiradi.

### 3. JavaScript va plagin'lar

JavaScript orqali real IP olib chiqilishi mumkin (WebRTC). Tor Browser default'da JavaScript'ni cheklaydi.

### 4. Exit relay HTTP'ni o'qiy oladi

HTTPS bo'lmagan saytda Exit relay sizning trafigingizni ko'ra oladi. **HTTPS doim majburiy.**

### 5. Tahliliy hujumlar

Davlat darajasidagi aktorlar (NSA, Mossad) trafik tahlili orqali Tor foydalanuvchilarini deanonimizatsiya qila olishi mumkin (real misol — Silk Road).

## 6. Eng yaxshi anonimlik amaliyoti

✅ **Qiling:**

- Tor Browser ichida turing — boshqa brauzer aralashtirmang.
- HTTPS faqat.
- Bridge'larni ishlating, agar Tor bloklangan bo'lsa.
- **Tails OS** — eng yuqori anonimlik (RAM'dan ishlaydi, hech narsa diskka yozilmaydi).
- AnonSurf'ni yodda saqlang (`anonsurf status`).

❌ **Qilmang:**

- Tor ichida shaxsiy hisoblarga login.
- BitTorrent (P2P tarmoqlar Tor'ni buzadi va sizni fosh qiladi).
- Tor Browser'da Flash, Java plagin'lari.
- Yangi profil — har sessiyada Tor Browser'ni yangidan ochish.

## 7. Tails OS — to'liq anonim Live OS

Eng yuqori anonimlik darajasi uchun [Tails](https://tails.net/) tavsiya etiladi:

- Live USB'dan ishlaydi.
- Hech narsa diskka yozilmaydi (RAM only).
- Hamma trafik majburiy Tor.
- Tugagandan keyin hech qanday iz qoldirmaydi.

Jurnalist, faol, whistleblower'lar uchun standart.

## 9. Eng tez-tez uchraydigan xatolar

- **AnonSurf yoqilgan deb tasdiqlamaslik** — `anonsurf status` ni tekshiring.
- **Tor Browser'da login** — Tor anonimlikni texnik berdi, lekin login sizni fosh qildi.
- **HTTP saytda** — Exit relay trafikni o'qiy oladi.
- **JavaScript yoqilgan** — fingerprinting xavfi.
- **BitTorrent Tor orqali** — P2P protokolarda real IP olib chiqiladi.
- **VPN + Tor** — odatda yaxshi, lekin notog'ri sozlangan VPN — fingerprinting.

## 10. Eng yaxshi amaliyot

- **Tor Browser default** — fingerprinting minimalik uchun.
- **Bridge'lar** agar Tor bloklangan bo'lsa: `https://bridges.torproject.org/`.
- **Daily security yangilanishlari** — Tor Browser har 2-3 haftada chiqadi.
- **NoScript va HTTPS Everywhere** — Tor Browser default keladi.
- **Real-life anonimlik kerak bo'lsa — Tails OS.**

## 12. Mashq

1. `sudo anonsurf start` ni bajaring (Parrot'da).
2. `anonsurf myip` orqali IP'ni ko'ring — bu sizning real IP'ngiz emasligini tekshiring.
3. Brauzer'da [check.torproject.org](https://check.torproject.org/) ga kiring. Tor orqali ulangansizmi?
4. `sudo anonsurf change` orqali Tor identity'ni o'zgartiring. Yangi IP keldimi?
5. `sudo anonsurf stop` orqali to'xtating.
