**Postfix** — Sendmail'ning modern alternativi, 1998-yilda IBM tomonidan boshlangan. Xavfsiz, tezkor, ko'p site'lar uchun. Bu darsda outbound (yuborish) va inbound (qabul) mail server'ni sozlaymiz.[¹](http://www.postfix.org/documentation.html)

<Callout type="info" title="Bu darsda nimani o'rganasiz">
- Postfix asosiy konfiguratsiyasi.
- Domain mail server (qabul + yuborish).
- DNS sozlamalari — MX, SPF, DKIM, DMARC.
- Anti-spam himoyasi.
- Dovecot bilan IMAP/POP3 (qisqacha).
</Callout>

## 1. Email infratuzilmasi

```
[Yuboruvchi] ──▶ [SMTP Server] ──▶ [Internet] ──▶ [Qabul SMTP] ──▶ [Maildir/Mailbox]
                                                                       │
                                                                       ↓
                                                                  [IMAP/POP3]
                                                                       │
                                                                       ↓
                                                                  [Klient]
```

| Komponent | Vositalar |
|---|---|
| SMTP server | Postfix, Exim, Sendmail |
| IMAP/POP3 | Dovecot, Cyrus |
| Anti-spam | SpamAssassin, rspamd |
| DKIM | OpenDKIM, rspamd |
| Webmail | Roundcube, Rainloop |

## 2. Postfix o'rnatish

```bash
sudo apt update
sudo DEBIAN_FRONTEND=noninteractive apt install postfix mailutils -y
```

`DEBIAN_FRONTEND=noninteractive` — interaktiv installer'ni o'tkazib yuboradi. Keyin qo'lda sozlash:

```bash
sudo dpkg-reconfigure postfix
```

Savollar:

- **General type:** Internet Site (mustaqil server).
- **System mail name:** mail.example.com (yoki example.com).
- **Root and postmaster mail recipient:** sizning user.
- **Other destinations:** `example.com, mail.example.com, localhost.localdomain, localhost`.
- **Force synchronous updates:** No.
- **Local networks:** `127.0.0.0/8 [::ffff:127.0.0.0]/104 [::1]/128`.
- **Mailbox size limit:** 0 (cheksiz) yoki ehtiyojga qarab.
- **Local address extension character:** `+`.
- **Internet protocols:** `all`.

## 3. Asosiy konfiguratsiya — `/etc/postfix/main.cf`

```
myhostname = mail.example.com
mydomain = example.com
myorigin = $mydomain

mydestination = $myhostname, localhost.$mydomain, localhost, $mydomain
mynetworks = 127.0.0.0/8 [::ffff:127.0.0.0]/104 [::1]/128

# Mailbox
home_mailbox = Maildir/

# Limits
mailbox_size_limit = 0
message_size_limit = 25600000   # 25 MB

# TLS (Let's Encrypt)
smtpd_use_tls = yes
smtpd_tls_cert_file = /etc/letsencrypt/live/mail.example.com/fullchain.pem
smtpd_tls_key_file = /etc/letsencrypt/live/mail.example.com/privkey.pem
smtpd_tls_security_level = may
smtp_tls_security_level = may

# Anti-spam
disable_vrfy_command = yes
smtpd_helo_required = yes
smtpd_recipient_restrictions =
    permit_mynetworks,
    permit_sasl_authenticated,
    reject_unauth_destination,
    reject_invalid_hostname,
    reject_non_fqdn_hostname,
    reject_non_fqdn_sender,
    reject_non_fqdn_recipient,
    reject_unknown_sender_domain,
    reject_unknown_recipient_domain,
    reject_rbl_client zen.spamhaus.org
```

```bash
sudo systemctl restart postfix
```

## 4. DNS yozuvlari — eng muhim

Mail server uchun DNS sozlash mass importance. Domain registrator yoki DNS provider'da:

### A record

```
mail.example.com.  IN  A  YOUR_SERVER_IP
```

### MX record

```
example.com.  IN  MX  10  mail.example.com.
```

10 — priority (kichikroq = yuqoriroq).

### SPF (Sender Policy Framework)

Kim sizning domen'ingiz nomidan email yubora oladi:

```
example.com.  IN  TXT  "v=spf1 ip4:YOUR_SERVER_IP mx ~all"
```

`~all` — soft fail (sinov), `-all` — hard fail (production).

### DKIM (sertifikat'li imzo)

Quyida OpenDKIM bilan sozlaymiz.

### DMARC (SPF + DKIM birga policy)

```
_dmarc.example.com.  IN  TXT  "v=DMARC1; p=quarantine; rua=mailto:dmarc@example.com"
```

`p=none` — sinov, `quarantine` — spam folder, `reject` — rad qilish.

### PTR (reverse DNS)

Cloud provider'da (DigitalOcean, AWS) sozlash. IP → mail.example.com.

## 6. SMTP authentication — Dovecot SASL bilan

Mijoz mail yuborish uchun login kerak:

```bash
sudo apt install dovecot-core dovecot-imapd -y
```

`/etc/dovecot/conf.d/10-master.conf`:

```
service auth {
    unix_listener /var/spool/postfix/private/auth {
        mode = 0666
        user = postfix
        group = postfix
    }
}
```

Postfix `main.cf`:

```
smtpd_sasl_type = dovecot
smtpd_sasl_path = private/auth
smtpd_sasl_auth_enable = yes
smtpd_sasl_security_options = noanonymous
smtpd_sasl_local_domain = $myhostname
broken_sasl_auth_clients = yes
```

```bash
sudo systemctl restart postfix dovecot
```

## 7. OpenDKIM

```bash
sudo apt install opendkim opendkim-tools -y

# Domain uchun key generatsiya
sudo mkdir -p /etc/opendkim/keys/example.com
cd /etc/opendkim/keys/example.com
sudo opendkim-genkey -s mail -d example.com
sudo mv mail.private mail
sudo chown opendkim:opendkim mail*
sudo chmod 600 mail

# Public key (DNS uchun)
cat mail.txt
```

DNS'ga TXT yozuv qo'shing:

```
mail._domainkey.example.com.  IN  TXT  "v=DKIM1; h=sha256; k=rsa; p=MIGfMA0GCS..."
```

`/etc/opendkim.conf`:

```
Domain example.com
KeyFile /etc/opendkim/keys/example.com/mail
Selector mail
Socket inet:8891@localhost
```

`/etc/postfix/main.cf` ga:

```
milter_default_action = accept
milter_protocol = 6
smtpd_milters = inet:127.0.0.1:8891
non_smtpd_milters = inet:127.0.0.1:8891
```

```bash
sudo systemctl restart opendkim postfix
```

## 9. Anti-spam — postgrey va spamassassin

```bash
sudo apt install postgrey spamassassin spamc -y

# postgrey — greylisting (vaqtinchalik tashlash, real mail server keyin qaytaradi)
sudo systemctl enable --now postgrey
```

Postfix `main.cf`:

```
smtpd_recipient_restrictions =
    ...
    check_policy_service inet:127.0.0.1:10023    # postgrey
```

## 10. IMAP/POP3 — Dovecot

`/etc/dovecot/conf.d/10-mail.conf`:

```
mail_location = maildir:~/Maildir
```

`/etc/dovecot/conf.d/10-auth.conf`:

```
disable_plaintext_auth = yes
auth_mechanisms = plain login
```

Klient (Thunderbird, K-9 Mail) uchun:

- **IMAP server:** mail.example.com, port 993 (SSL/TLS).
- **SMTP server:** mail.example.com, port 587 (STARTTLS).
- **Username:** unix user.

## 13. Eng tez-tez uchraydigan xatolar

- **PTR yo'q yoki noto'g'ri** — emailingiz Gmail/Outlook'da spam'ga tushadi.
- **DKIM key DNS'da yo'q** — DKIM tekshiruv fail.
- **SPF `~all`'dan `-all`'ga juda erta o'tish** — legit mail rad qilinadi.
- **TLS sertifikat eskirgan** — mail server'lar TLS ishonmaydi.
- **Port 25 cloud provider'da bloklangan** — AWS, GCP default'da chiqish'ni rad qiladi (spam himoyasi). Submission port 587 yoki SMTP relay.

## 14. Eng yaxshi amaliyot

- **DNS yozuvlari to'g'ri sozlash birinchi.**
- **mail-tester.com 10/10 ball** — eng yuqori deliverability.
- **OpenDKIM** majburiy modern email uchun.
- **DMARC `p=quarantine`** — boshlash, keyin `reject`.
- **Backup MX server** — primary down bo'lsa.
- **Greylisting** — spam'ning 90%+ ni to'sadi.
- **TLS majburiy** — modern mail server'lar plain text rad qiladi.
- **Loglarni monitor** — `fail2ban` bilan birga.
- **Modern alternative — Mailcow yoki Mail-in-a-Box** — Docker-asoslangan, oson o'rnatish.
