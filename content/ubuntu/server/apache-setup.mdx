**Apache HTTP Server** — eng mashhur web server (dunyo bo'yicha). Modular arxitektura — kerak modullarni yoqib o'chirish, virtual hosts, `.htaccess`, ko'p funksiya.[¹](https://httpd.apache.org/docs/)

<Callout type="info" title="Bu darsda nimani o'rganasiz">
- `apache2` o'rnatish.
- `sites-available` / `sites-enabled` / `mods-enabled`.
- Virtual hosts.
- Modullar — `mod_rewrite`, `mod_ssl`, `mod_proxy`.
- `.htaccess` — per-directory config.
- Let's Encrypt.
</Callout>

## 1. O'rnatish

```bash
sudo apt update
sudo apt install -y apache2

sudo systemctl enable --now apache2

# Tekshirish
curl http://localhost
# <html>... Apache2 Ubuntu Default Page
```

UFW:

```bash
sudo ufw allow 'Apache Full'    # 80 + 443
```

## 2. Fayl tuzilishi

```
/etc/apache2/
├── apache2.conf             # asosiy
├── ports.conf               # Listen port'lar
├── envvars                  # environment
├── sites-available/
│   ├── 000-default.conf     # default :80
│   └── default-ssl.conf     # default :443
├── sites-enabled/           # symlinks
├── mods-available/
│   ├── rewrite.load
│   ├── ssl.load
│   └── ...
├── mods-enabled/            # symlinks
├── conf-available/
└── conf-enabled/
```

Web root: `/var/www/html/`.
Log'lar: `/var/log/apache2/`.

## 3. Boshqaruv buyruqlari

```bash
# Boshqaruv
sudo systemctl start apache2
sudo systemctl stop apache2
sudo systemctl reload apache2     # config qayta o'qish (downtime'siz)
sudo systemctl restart apache2

# Status
sudo systemctl status apache2

# Config sintaksis test
sudo apache2ctl configtest
# yoki
sudo apache2ctl -t
```

## 4. Modullar

```bash
# Mavjud modullar
ls /etc/apache2/mods-available/

# Yoqilgan
apache2ctl -M

# Yoqish
sudo a2enmod rewrite
sudo a2enmod ssl
sudo a2enmod headers
sudo a2enmod proxy proxy_http

# O'chirish
sudo a2dismod autoindex

sudo systemctl restart apache2
```

Eng ko'p ishlatilgan:

- `rewrite` — URL rewriting (`.htaccess`).
- `ssl` — HTTPS.
- `headers` — security headers.
- `proxy`, `proxy_http`, `proxy_balancer` — reverse proxy, load balancer.
- `mod_php` (yoki `proxy_fcgi` PHP-FPM uchun).

## 5. Virtual host

`/etc/apache2/sites-available/example.com.conf`:

```apache
<VirtualHost *:80>
    ServerName example.com
    ServerAlias www.example.com
    ServerAdmin admin@example.com

    DocumentRoot /var/www/example.com

    <Directory /var/www/example.com>
        Options Indexes FollowSymLinks
        AllowOverride All
        Require all granted
    </Directory>

    ErrorLog ${APACHE_LOG_DIR}/example.com-error.log
    CustomLog ${APACHE_LOG_DIR}/example.com-access.log combined
</VirtualHost>
```

Yoqish:

```bash
sudo a2ensite example.com
sudo a2dissite 000-default       # opsional
sudo apache2ctl configtest
sudo systemctl reload apache2
```

## 6. `.htaccess`

`AllowOverride All` yoqilgan bo'lsa, `/var/www/example.com/.htaccess`:

```apache
# Mod_rewrite — URL rewriting
RewriteEngine On

# WWW redirect
RewriteCond %{HTTP_HOST} ^example\.com$ [NC]
RewriteRule ^(.*)$ https://www.example.com/$1 [L,R=301]

# Slash redirect
RewriteRule ^old-page$ /new-page [L,R=301]

# Pretty URLs (Laravel/WordPress)
RewriteCond %{REQUEST_FILENAME} !-d
RewriteCond %{REQUEST_FILENAME} !-f
RewriteRule . index.php [L]

# Block IP
Require not ip 192.168.1.100

# Auth
AuthType Basic
AuthName "Admin Area"
AuthUserFile /etc/apache2/.htpasswd
Require valid-user
```

`.htpasswd` yaratish:

```bash
sudo apt install -y apache2-utils
sudo htpasswd -c /etc/apache2/.htpasswd admin
```

## 7. SSL — Let's Encrypt

```bash
sudo apt install -y certbot python3-certbot-apache

sudo certbot --apache -d example.com -d www.example.com
# Avtomatik 80 → 443 redirect
```

SSL virtual host:

```apache
<VirtualHost *:443>
    ServerName example.com
    DocumentRoot /var/www/example.com

    SSLEngine on
    SSLCertificateFile /etc/letsencrypt/live/example.com/fullchain.pem
    SSLCertificateKeyFile /etc/letsencrypt/live/example.com/privkey.pem
    Include /etc/letsencrypt/options-ssl-apache.conf
</VirtualHost>

<VirtualHost *:80>
    ServerName example.com
    Redirect permanent / https://example.com/
</VirtualHost>
```

## 8. PHP — mod_php yoki PHP-FPM

### mod_php (oddiy)

```bash
sudo apt install -y libapache2-mod-php
# PHP fayllari avtomatik ishlaydi
```

### PHP-FPM (tezroq, multi-process)

```bash
sudo apt install -y php-fpm
sudo a2enmod proxy_fcgi setenvif
sudo a2enconf php8.2-fpm

sudo systemctl restart apache2
```

Virtual host'da:

```apache
<FilesMatch \.php$>
    SetHandler "proxy:unix:/run/php/php8.2-fpm.sock|fcgi://localhost"
</FilesMatch>
```

## 9. Reverse proxy

```apache
<VirtualHost *:80>
    ServerName api.example.com

    ProxyPreserveHost On
    ProxyPass / http://127.0.0.1:3000/
    ProxyPassReverse / http://127.0.0.1:3000/

    RequestHeader set X-Real-IP %{REMOTE_ADDR}s
    RequestHeader set X-Forwarded-For %{REMOTE_ADDR}s
    RequestHeader set X-Forwarded-Proto "http"
</VirtualHost>
```

```bash
sudo a2enmod proxy proxy_http headers
sudo systemctl restart apache2
```

## 10. Load balancing

```apache
<Proxy balancer://mycluster>
    BalancerMember http://10.0.0.10:8080
    BalancerMember http://10.0.0.11:8080
    BalancerMember http://10.0.0.12:8080 status=+H
    ProxySet lbmethod=byrequests
</Proxy>

<VirtualHost *:80>
    ServerName api.example.com
    ProxyPass / balancer://mycluster/
    ProxyPassReverse / balancer://mycluster/
</VirtualHost>
```

```bash
sudo a2enmod proxy_balancer lbmethod_byrequests
```

`status=+H` — hot standby (backup).

## 11. Security headers

```apache
<IfModule mod_headers.c>
    Header always set X-Frame-Options "SAMEORIGIN"
    Header always set X-Content-Type-Options "nosniff"
    Header always set Referrer-Policy "strict-origin-when-cross-origin"
    Header always set X-XSS-Protection "1; mode=block"
    Header always set Strict-Transport-Security "max-age=31536000; includeSubDomains"
</IfModule>
```

## 12. Compression

```apache
<IfModule mod_deflate.c>
    AddOutputFilterByType DEFLATE text/html text/css text/javascript
    AddOutputFilterByType DEFLATE application/javascript application/json
    AddOutputFilterByType DEFLATE image/svg+xml
</IfModule>
```

## 13. Cache headers

```apache
<IfModule mod_expires.c>
    ExpiresActive On
    ExpiresByType image/jpg "access plus 1 year"
    ExpiresByType image/png "access plus 1 year"
    ExpiresByType text/css "access plus 1 month"
    ExpiresByType application/javascript "access plus 1 month"
    ExpiresByType text/html "access plus 0 seconds"
</IfModule>
```

```bash
sudo a2enmod expires
sudo systemctl reload apache2
```

## 14. mpm — multi-processing module

Apache `mpm` (event/worker/prefork) — request handling strategiyasi:

- **`prefork`** — har request alohida process. mod_php uchun zarur.
- **`worker`** — har process'da threads.
- **`event`** — eng tez, async (default Ubuntu 22+).

Tekshirish:

```bash
apache2ctl -V | grep MPM
# Server MPM:     event
```

PHP-FPM bilan `event` yoki `worker` — eng yuqori performance.

## 15. Log format

```apache
LogFormat "%h %l %u %t \"%r\" %>s %b \"%{Referer}i\" \"%{User-Agent}i\" %D" combined-time
CustomLog ${APACHE_LOG_DIR}/access.log combined-time
```

`%D` — request duration (microseconds).

## 16. Apache vs Nginx

| Xususiyat | Apache | Nginx |
|---|---|---|
| Arxitektura | Process-based | Event-driven |
| Performance static | Yaxshi | Eng tez |
| `.htaccess` | Default | Yo'q |
| Modullar | Ko'p | Cheklangan |
| Konfiguratsiya | Verbose | Lakon |
| PHP | mod_php yoki FPM | Faqat FPM |

## 17. Eng tez-tez uchraydigan xatolar

- **`a2ensite` qilmaslik** — site mavjud, lekin ishlamaydi.
- **`AllowOverride None`** — `.htaccess` ishlamaydi.
- **`prefork` + threading PHP** — race condition.
- **`AllowOverride All` production'da** — performance pasayadi.
- **SSL cipher zaif** — `options-ssl-apache.conf` ishlatish.

## 18. Eng yaxshi amaliyot

- **`apache2ctl configtest` har vaqt** — reload'dan oldin.
- **`event` MPM + PHP-FPM** — eng yaxshi performance.
- **`.htaccess` o'rniga main config** — agar mumkin (performance).
- **Security headers** — har site uchun.
- **Log analizi** — `goaccess`, `awstats`.

## 19. Mashqlar

2. **Virtual host:** `example.com` uchun config.
