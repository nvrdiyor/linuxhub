**PostgreSQL** — eng kuchli open-source RDBMS. Ubuntu'da default 14/15 versiya, lekin rasmiy PGDG repository orqali eng yangi versiyani olish mumkin.[¹](https://www.postgresql.org/docs/)

<Callout type="info" title="Bu darsda nimani o'rganasiz">
- PostgreSQL o'rnatish (Ubuntu repo va PGDG).
- `postgres` user va `psql`.
- Foydalanuvchi va database yaratish.
- `pg_hba.conf` — kim ulana oladi.
- `pg_dump` / `pg_restore`.
- Streaming replication.
</Callout>

## 1. O'rnatish — Ubuntu repo

```bash
sudo apt update
sudo apt install -y postgresql postgresql-contrib

sudo systemctl enable --now postgresql
sudo systemctl status postgresql

# Versiya
psql --version
# psql (PostgreSQL) 15.x
```

## 2. PGDG repo (eng yangi versiya)

PostgreSQL'ning rasmiy Apt repository — har vaqt eng yangi:

```bash
sudo apt install -y curl ca-certificates
sudo install -d /usr/share/postgresql-common/pgdg
sudo curl -o /usr/share/postgresql-common/pgdg/apt.postgresql.org.asc \
    --fail https://www.postgresql.org/media/keys/ACCC4CF8.asc

# Repository qo'shish
sudo sh -c 'echo "deb [signed-by=/usr/share/postgresql-common/pgdg/apt.postgresql.org.asc] https://apt.postgresql.org/pub/repos/apt $(lsb_release -cs)-pgdg main" > /etc/apt/sources.list.d/pgdg.list'

sudo apt update
sudo apt install -y postgresql-17    # eng yangi
```

## 3. `postgres` system user

PostgreSQL'da default — `postgres` system user va `postgres` DB user.

```bash
# Ulanish
sudo -u postgres psql

# Yoki shell
sudo -u postgres bash
psql
```

`psql` ichida:

```sql
\l         -- database ro'yxati
\du        -- user ro'yxati
\c db      -- database tanlash
\d         -- jadval'lar
\d table   -- jadval struktura
\q         -- chiqish
```

## 4. Foydalanuvchi va database

```sql
-- Yangi user
CREATE USER myapp WITH PASSWORD 'StrongPass123!';

-- Database
CREATE DATABASE myapp_db OWNER myapp;

-- Privilege
GRANT ALL PRIVILEGES ON DATABASE myapp_db TO myapp;

-- Ro'yxat
\du
\l

-- O'chirish
DROP DATABASE myapp_db;
DROP USER myapp;
```

CLI'da:

```bash
sudo -u postgres createuser --pwprompt myapp
sudo -u postgres createdb -O myapp myapp_db
```

## 5. `pg_hba.conf` — autentifikatsiya

`/etc/postgresql/15/main/pg_hba.conf` (versiya'ga qarab):

```
# TYPE  DATABASE  USER       ADDRESS         METHOD

# "local" — Unix socket
local   all       postgres                   peer
local   all       all                        peer

# IPv4 local
host    all       all        127.0.0.1/32    scram-sha-256

# Remote subnet
host    myapp_db  myapp      10.0.0.0/24     scram-sha-256

# Trust (xavfli, faqat dev)
# host    all       all        0.0.0.0/0       trust
```

`METHOD`:

- `peer` — Unix user = DB user (local'da).
- `md5` — eski parol hash.
- `scram-sha-256` — zamonaviy parol.
- `trust` — hech qanday tekshirish (XAVFLI).
- `reject` — bloklash.

```bash
sudo systemctl reload postgresql
```

## 8. Backup — `pg_dump`

```bash
# Bitta DB
sudo -u postgres pg_dump myapp_db > /tmp/myapp_db.sql

# Custom format (recommended)
sudo -u postgres pg_dump -Fc myapp_db > /tmp/myapp_db.dump

# Compressed plain
sudo -u postgres pg_dump myapp_db | gzip > /tmp/myapp_db.sql.gz

# Hammasi
sudo -u postgres pg_dumpall > /tmp/all.sql

# Faqat struktura
sudo -u postgres pg_dump --schema-only myapp_db > /tmp/schema.sql

# Faqat data
sudo -u postgres pg_dump --data-only myapp_db > /tmp/data.sql
```

## 9. Restore

```bash
# Plain SQL
sudo -u postgres psql myapp_db_new < /tmp/myapp_db.sql

# Custom format
sudo -u postgres pg_restore -d myapp_db_new /tmp/myapp_db.dump

# Compressed
gunzip -c /tmp/myapp_db.sql.gz | sudo -u postgres psql myapp_db_new
```

DB avval yaratilgan bo'lishi kerak:

```bash
sudo -u postgres createdb myapp_db_new
```

## 10. Avtomatik backup

`/usr/local/bin/pg-backup.sh`:

```bash
#!/bin/bash
set -e

BACKUP_DIR="/var/backups/postgres"
DATE=$(date +%Y%m%d-%H%M%S)
RETENTION=14

mkdir -p "$BACKUP_DIR"

# Per-database
for DB in $(sudo -u postgres psql -lqt | awk '{print $1}' | grep -vE '^$|template|^postgres$'); do
    sudo -u postgres pg_dump -Fc "$DB" > "$BACKUP_DIR/$DB-$DATE.dump"
done

# Globals (users, tablespaces)
sudo -u postgres pg_dumpall --globals-only > "$BACKUP_DIR/globals-$DATE.sql"

# Cleanup
find "$BACKUP_DIR" -mtime +$RETENTION -delete
```

```bash
sudo chmod +x /usr/local/bin/pg-backup.sh
echo "0 3 * * * /usr/local/bin/pg-backup.sh" | sudo tee /etc/cron.d/pg-backup
```

## 11. Streaming replication

### Master

`postgresql.conf`:

```
listen_addresses = '*'
wal_level = replica
max_wal_senders = 5
wal_keep_size = 1GB
```

`pg_hba.conf`:

```
host    replication    replicator    10.0.1.0/24    scram-sha-256
```

```sql
CREATE USER replicator WITH REPLICATION ENCRYPTED PASSWORD 'replpass';
```

```bash
sudo systemctl restart postgresql
```

### Standby

```bash
# Master'dan to'liq base backup
sudo systemctl stop postgresql
sudo -u postgres rm -rf /var/lib/postgresql/15/main/*

sudo -u postgres pg_basebackup \
    -h MASTER_IP -U replicator \
    -D /var/lib/postgresql/15/main \
    -P -v -R -X stream
```

`-R` — `standby.signal` va `postgresql.auto.conf` ga primary_conninfo qo'shadi.

```bash
sudo systemctl start postgresql
```

Master'da:

```sql
SELECT * FROM pg_stat_replication;
```

## 12. Performance tuning

`postgresql.conf`:

```
# Memory
shared_buffers = 4GB              # RAM'ning 25%
effective_cache_size = 12GB       # RAM'ning 75%
work_mem = 16MB
maintenance_work_mem = 512MB

# Checkpoints
checkpoint_completion_target = 0.9
wal_buffers = 16MB

# Planner
random_page_cost = 1.1            # SSD
effective_io_concurrency = 200

# Connections
max_connections = 100

# Logging
logging_collector = on
log_directory = 'log'
log_min_duration_statement = 1000  # 1s'dan ortiq
log_line_prefix = '%t [%p]: user=%u,db=%d,app=%a,client=%h '
```

```bash
sudo systemctl restart postgresql
```

## 13. Monitoring — `pg_stat_*`

```sql
-- Aktiv ulanishlar
SELECT * FROM pg_stat_activity WHERE state = 'active';

-- Eng katta jadval'lar
SELECT schemaname, tablename, pg_size_pretty(pg_total_relation_size(schemaname||'.'||tablename)) AS size
FROM pg_tables
WHERE schemaname NOT IN ('pg_catalog','information_schema')
ORDER BY pg_total_relation_size(schemaname||'.'||tablename) DESC
LIMIT 10;

-- Sekin query'lar (log'dan)
SELECT * FROM pg_stat_statements ORDER BY total_exec_time DESC LIMIT 10;
```

`pg_stat_statements` yoqilgan bo'lishi kerak.

## 15. VACUUM va ANALYZE

PostgreSQL — MVCC, eski row'lar saqlanadi:

```sql
-- Manual
VACUUM ANALYZE app.users;

-- Aggressive
VACUUM FULL app.users;       -- jadvalni qisqartiradi (lock)

-- Auto-vacuum (default yoqilgan)
SHOW autovacuum;
```

## 16. Eng tez-tez uchraydigan xatolar

- **`peer` auth — boshqa OS user'dan ulanish** — `unix socket` faqat o'sha user uchun.
- **`listen_addresses = 'localhost'`** — remote ulanish mumkin emas.
- **`pg_hba.conf` o'zgartirib reload qilmaslik** — eski qoidalar amal qilmoqda.
- **Backup faqat `pg_dump`** — config va WAL fayllarini ham saqlang.
- **`shared_buffers` past** — performance pasayadi.

## 17. Eng yaxshi amaliyot

- **PGDG repository** — eng yangi versiya.
- **`scram-sha-256` auth** — `md5` o'rniga.
- **`pg_dump -Fc`** — custom format, parallel restore.
- **Streaming replication** — high availability.
- **Monitoring `pg_stat_*`** — performance.
