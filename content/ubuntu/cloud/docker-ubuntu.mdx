**Docker** — kontayner platforma. Ubuntu Server'da rasmiy Docker repository orqali eng yangi versiya o'rnatiladi.[¹](https://docs.docker.com/engine/install/ubuntu/)

<Callout type="info" title="Bu darsda nimani o'rganasiz">
- Eski Docker'ni o'chirish.
- Rasmiy Docker repository qo'shish.
- `docker` va `docker compose` o'rnatish.
- `usermod -aG docker`.
- Multi-container `docker-compose.yml`.
- Resurs limit va security.
</Callout>

## 1. Eski Docker o'chirish

Ubuntu repo'dagi eski `docker.io` o'chirish:

```bash
for pkg in docker.io docker-doc docker-compose docker-compose-v2 podman-docker containerd runc; do
    sudo apt remove -y $pkg 2>/dev/null || true
done
```

## 2. Rasmiy repository

```bash
# Dependency
sudo apt update
sudo apt install -y ca-certificates curl gnupg

# Docker GPG key
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg \
    -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc

# Repository
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.asc] \
    https://download.docker.com/linux/ubuntu $(. /etc/os-release && echo $VERSION_CODENAME) stable" | \
    sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

sudo apt update
```

## 3. O'rnatish

```bash
sudo apt install -y docker-ce docker-ce-cli containerd.io \
    docker-buildx-plugin docker-compose-plugin

# Versiya
docker --version
# Docker version 27.x.x

docker compose version
# Docker Compose version v2.x.x
```

## 4. Service va test

```bash
sudo systemctl enable --now docker

# Test
sudo docker run hello-world
```

## 5. `sudo'siz` Docker — user guruh

```bash
sudo usermod -aG docker $USER

# Yangi guruh aktivatsiya (logout/login yoki):
newgrp docker

# Test
docker run hello-world
```

<Callout type="warning" title="Docker guruh — root teng">
Docker guruh root privilege'ga teng (any container'dan host disk mount). Ishonchli foydalanuvchilarga bering.
</Callout>

## 6. Asosiy buyruqlar

```bash
# Image
docker pull nginx:alpine
docker images
docker rmi nginx:alpine

# Container
docker run -d --name web -p 8080:80 nginx:alpine
docker ps
docker ps -a            # to'xtaganlar ham
docker logs web
docker logs -f web      # follow
docker exec -it web sh
docker stop web
docker rm web

# Cleanup
docker system prune     # eski image, container, network
docker system prune -a  # barcha unused
```

## 7. Docker Compose

`docker-compose.yml` — multi-container ilovalar:

```yaml
version: "3.9"

services:
  web:
    image: nginx:alpine
    ports:
      - "8080:80"
    volumes:
      - ./html:/usr/share/nginx/html:ro
      - ./nginx.conf:/etc/nginx/conf.d/default.conf:ro
    depends_on:
      - api
    restart: unless-stopped

  api:
    build: ./api
    environment:
      DATABASE_URL: postgres://user:pass@db:5432/mydb
    depends_on:
      db:
        condition: service_healthy
    restart: unless-stopped

  db:
    image: postgres:16-alpine
    environment:
      POSTGRES_USER: user
      POSTGRES_PASSWORD: pass
      POSTGRES_DB: mydb
    volumes:
      - pgdata:/var/lib/postgresql/data
    healthcheck:
      test: ["CMD-SHELL", "pg_isready -U user"]
      interval: 5s
      timeout: 3s
      retries: 5

volumes:
  pgdata:
```

```bash
docker compose up -d
docker compose ps
docker compose logs -f api
docker compose down
docker compose down -v    # volume'larni ham o'chirish
```

## 8. Network

```bash
# Default networks
docker network ls
# bridge, host, none

# Custom network
docker network create mynet

docker run -d --name db --network mynet postgres:16
docker run -d --name app --network mynet myapp
# `app` ichidan `db` hostname orqali ulanish mumkin
```

Compose avtomatik network yaratadi.

## 9. Volumes

```bash
# Named volume
docker volume create mydata
docker run -v mydata:/data ubuntu

# Bind mount
docker run -v /host/path:/container/path ubuntu

# Read-only
docker run -v /host/conf:/etc/app/conf:ro ubuntu

# Anonymous (har container'ga yangi)
docker run -v /data ubuntu
```

Volume joyi: `/var/lib/docker/volumes/`.

## 10. Resurs limit

```bash
# CPU
docker run --cpus=2 myapp           # 2 CPU yadrosi
docker run --cpu-shares=512 myapp   # relative weight

# Memory
docker run -m 512m myapp
docker run -m 1g --memory-swap=2g myapp

# Disk I/O
docker run --device-read-bps /dev/sda:10mb myapp
```

Compose'da:

```yaml
services:
  api:
    deploy:
      resources:
        limits:
          cpus: "2"
          memory: 1G
        reservations:
          cpus: "0.5"
          memory: 256M
```

## 11. Security — non-root user

`Dockerfile`:

```dockerfile
FROM node:20-alpine
RUN addgroup -S app && adduser -S app -G app
WORKDIR /app
COPY --chown=app:app . .
USER app
CMD ["node", "server.js"]
```

`docker run --user 1000:1000` ham mumkin.

## 12. Read-only filesystem

```bash
docker run --read-only --tmpfs /tmp myapp
```

Container faqat o'qiy oladi (xavfsizroq).

## 13. Capabilities

```bash
# Hammasi drop, faqat zarurlari add
docker run --cap-drop=ALL --cap-add=NET_BIND_SERVICE nginx
```

Default Docker capability'lari ko'p — o'chirish xavfsizlik.

## 14. Registry — private

```bash
# Docker Hub login
docker login

# Custom registry
docker login registry.example.com

# Push
docker tag myapp:1.0 registry.example.com/myapp:1.0
docker push registry.example.com/myapp:1.0

# Pull
docker pull registry.example.com/myapp:1.0
```

## 15. Logging driver

`/etc/docker/daemon.json`:

```json
{
  "log-driver": "json-file",
  "log-opts": {
    "max-size": "10m",
    "max-file": "3"
  }
}
```

```bash
sudo systemctl restart docker
```

`max-size` muhim — log'lar disk to'ldirishini oldini oladi.

## 16. Backup va restore container

```bash
# Container snapshot
docker commit web my-nginx-backup:v1

# Image export
docker save my-nginx-backup:v1 | gzip > backup.tar.gz

# Import
gunzip -c backup.tar.gz | docker load

# Volume backup
docker run --rm -v mydata:/data -v $(pwd):/backup ubuntu \
    tar czf /backup/mydata.tar.gz -C /data .
```

## 17. Misol — to'liq web stack

`docker-compose.yml`:

```yaml
version: "3.9"

services:
  app:
    image: node:20-alpine
    working_dir: /app
    command: ["node", "server.js"]
    volumes:
      - ./app:/app
    environment:
      NODE_ENV: production
      DATABASE_URL: postgres://app:pass@db:5432/mydb
      REDIS_URL: redis://redis:6379
    depends_on:
      - db
      - redis
    restart: always

  db:
    image: postgres:16-alpine
    environment:
      POSTGRES_USER: app
      POSTGRES_PASSWORD: pass
      POSTGRES_DB: mydb
    volumes:
      - pgdata:/var/lib/postgresql/data
    restart: always

  redis:
    image: redis:7-alpine
    volumes:
      - redisdata:/data
    restart: always

  nginx:
    image: nginx:alpine
    ports:
      - "80:80"
      - "443:443"
    volumes:
      - ./nginx.conf:/etc/nginx/nginx.conf:ro
      - ./certs:/etc/nginx/certs:ro
    depends_on:
      - app
    restart: always

volumes:
  pgdata:
  redisdata:
```

```bash
docker compose up -d
docker compose logs -f
```

## 18. Eng tez-tez uchraydigan xatolar

- **`docker.io` Ubuntu repo eski** — rasmiy `docker-ce` ishlating.
- **`docker` guruhga qo'shilmasdan `sudo docker`** — har vaqt sudo.
- **`-p HOST:CONTAINER` aralash** — `8080:80` → host 8080 → container 80.
- **Volume bind mount yo'l mavjud emas** — Docker yo'lni avtomatik yaratadi.
- **Log rotation yo'q** — `daemon.json`'da `max-size` qo'ying.

## 19. Eng yaxshi amaliyot

- **Rasmiy Docker repo** — eng yangi versiya.
- **Multi-stage Dockerfile** — kichik image.
- **Non-root user** — security.
- **Named volume** — bind mount o'rniga (portable).
- **`docker compose`** — `docker-compose` (V1) o'rniga.
- **Resurs limit** — har container.

## 20. Mashqlar

1. **O'rnatish:** Docker rasmiy repo'dan.
2. **User guruh:** `sudo` siz `docker ps`.
3. **Compose:** Nginx + PostgreSQL stack.
4. **Volume backup:** `pgdata` ni tar.gz qiling.
5. **Security:** Non-root user bilan ishlaydigan image.

- c) Yo'q
- d) Hech farq qilmaydi

**Savol 2.** Docker guruh privilege:

- b) Root teng (xavfli)

- a) Background'da ishga tushiradi

- c) Logs ko'rsatadi
- d) Update

<Callout type="success" title="Javob">
**(a)** `-d` = detached — background, terminal'ni egallamaydi.
</Callout>

**Savol 4.** Named volume vs bind mount:

- a) Bir xil
- b) Named — Docker boshqaradi (portable), bind — host yo'l
- c) Bind tezroq
- d) Named tezroq

<Callout type="success" title="Javob">
**(b)** Named portable (Docker volume location), bind mount aniq host path.
</Callout>

**Savol 5.** Log rotation:

- a) Avtomatik default
- b) `daemon.json`'da `max-size` va `max-file` belgilash
- c) `logrotate`
- d) Hech narsa

<Callout type="success" title="Javob">
**(b)** Docker default'da log limit yo'q — disk to'lib qoladi.
