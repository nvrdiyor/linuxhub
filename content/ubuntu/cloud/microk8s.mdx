**MicroK8s** — Canonical'ning yengil, production-grade Kubernetes distrosi. Snap orqali bir buyruq bilan o'rnatiladi. IoT, edge, dev va kichik production uchun ideal.[¹](https://microk8s.io/docs)

<Callout type="info" title="Bu darsda nimani o'rganasiz">
- MicroK8s snap orqali o'rnatish.
- Addon ekosistemasi (`microk8s enable ...`).
- Cluster (multi-node) qurish.
- HA — 3 node'dan.
- MicroK8s vs Minikube vs k3s.
</Callout>

## 1. O'rnatish

```bash
sudo snap install microk8s --classic

# User'ni `microk8s` guruhga
sudo usermod -aG microk8s $USER
sudo chown -R $USER ~/.kube
newgrp microk8s

# Status (1-2 daqiqa kuting)
microk8s status --wait-ready
```

## 2. kubectl alias

```bash
# microk8s ichidagi kubectl
microk8s kubectl get nodes

# Alias
sudo snap alias microk8s.kubectl kubectl

# Endi
kubectl get nodes
```

Yoki kubeconfig export:

```bash
microk8s config > ~/.kube/config
chmod 600 ~/.kube/config
kubectl get nodes
```

## 3. Addon'lar

Eng foydali — addon ekosistemasi:

```bash
microk8s status

# Yoqish
microk8s enable dns
microk8s enable storage
microk8s enable ingress
microk8s enable dashboard
microk8s enable registry
microk8s enable metallb:10.64.140.43-10.64.140.49
microk8s enable cert-manager
microk8s enable observability    # Prometheus + Grafana
microk8s enable helm3

# O'chirish
microk8s disable dashboard
```

To'liq ro'yxat: `microk8s status` yoki rasmiy docs.

## 4. Cluster (multi-node)

### Master

```bash
# Master node
microk8s add-node
# Quyidagi token chiqadi:
# microk8s join 10.0.0.10:25000/abc.../xxx
```

### Worker

```bash
# Worker node — masterdagi tokenni ishlating
microk8s join 10.0.0.10:25000/abc.../xxx
```

Tekshirish:

```bash
microk8s kubectl get nodes
# NAME       STATUS   ROLES                  AGE
# master     Ready    control-plane,master   10m
# worker-1   Ready    worker                 1m
```

## 5. HA — High Availability

3 ta master node (etcd quorum):

```bash
# 1-master
microk8s enable ha-cluster

# 2 va 3-master
microk8s add-node          # masterdan
microk8s join ...
```

3 node'dan ko'p — HA avtomatik ishlaydi.

```bash
microk8s status
# high-availability: yes
# datastore master nodes: 3
```

## 6. Storage

```bash
microk8s enable hostpath-storage    # local
# yoki
microk8s enable mayastor            # production storage
```

PVC yaratish:

```yaml
apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: data-pvc
spec:
  accessModes:
  - ReadWriteOnce
  resources:
    requests:
      storage: 5Gi
  storageClassName: microk8s-hostpath
```

## 7. Ingress

```bash
microk8s enable ingress

# Test
kubectl create deployment nginx --image=nginx
kubectl expose deployment nginx --port=80
```

`ingress.yaml`:

```yaml
apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  name: nginx-ing
spec:
  rules:
  - host: nginx.local
    http:
      paths:
      - path: /
        pathType: Prefix
        backend:
          service:
            name: nginx
            port:
              number: 80
```

```bash
kubectl apply -f ingress.yaml
echo "$(hostname -I | awk '{print $1}') nginx.local" | sudo tee -a /etc/hosts
curl http://nginx.local
```

## 9. Dashboard

```bash
microk8s enable dashboard

# Token
microk8s kubectl -n kube-system get secret \
    $(microk8s kubectl -n kube-system get sa kubernetes-dashboard -o jsonpath='{.secrets[0].name}') \
    -o jsonpath='{.data.token}' | base64 -d
echo

# Proxy
microk8s dashboard-proxy
# https://127.0.0.1:10443
```

## 10. Helm 3

```bash

```

## 11. Observability — Prometheus + Grafana

```bash
microk8s enable observability

# Tekshirish
kubectl get pods -n observability
kubectl get svc -n observability

# Grafana — port-forward
kubectl port-forward -n observability svc/kube-prom-stack-grafana 3000:80

# Brauzer: http://localhost:3000
# admin / prom-operator
```

## 12. Stop/Start/Reset

```bash
# Stop
microk8s stop

# Start
microk8s start

# Reset (hammasini o'chiradi, addon'lar saqlanadi)
microk8s reset

# Snap o'chirish
sudo snap remove microk8s --purge
```

## 13. MicroK8s vs Minikube vs k3s

| Xususiyat | MicroK8s | Minikube | k3s |
|---|---|---|---|
| Sotuvchi | Canonical | Kubernetes SIG | Rancher |
| Boot | Snap | Binary | Curl + sh |
| Versiya | Multiple channels | Versiya tanlash | Latest stable |
| Resurs | O'rta | O'rta | Eng kichik |
| Multi-node | Ha | Ha (eksperimental) | Ha |
| Production | Edge/IoT | Faqat dev | Production edge |
| Addons | `enable ...` | `addons enable` | Helm orqali |

## 14. Misol — to'liq web app

```bash
# Stack o'rnatish
microk8s enable dns ingress storage

# WordPress
microk8s helm3 install wp bitnami/wordpress \
    --set service.type=ClusterIP \
    --set ingress.enabled=true \
    --set ingress.hostname=wp.local

# /etc/hosts
echo "$(hostname -I | awk '{print $1}') wp.local" | sudo tee -a /etc/hosts

# Brauzer: http://wp.local
```

## 17. Eng tez-tez uchraydigan xatolar

- **`microk8s` guruhga qo'shilmasdan** — har vaqt `sudo`.
- **DNS yoqilmagan** — Service ishlamaydi.
- **Storage yo'q** — PVC `Pending` qoladi.
- **MetalLB pool noto'g'ri IP range** — LoadBalancer mavjud emas.
- **`microk8s.kubectl` va `kubectl` farqi** — alias yoki kubeconfig export.

## 18. Eng yaxshi amaliyot

- **Addon'lar bosqichma-bosqich** — bir martda kerakli'lari.
- **HA 3 node'dan** — quorum uchun.
- **Helm3 paketlar** — production paketlar.
- **Observability** — boshlanishidan monitoring.
- **`kubectl` alias** — `microk8s.kubectl` har vaqt yozmasdan.

## 19. Mashqlar
