**Minikube** — lokal kompyuter'da bitta-tugun Kubernetes cluster. Kubernetes'ni o'rganish, ilovani test qilish uchun ideal. Ubuntu'da bir necha buyruq bilan.[¹](https://minikube.sigs.k8s.io/docs/)

<Callout type="info" title="Bu darsda nimani o'rganasiz">
- Minikube va `kubectl` o'rnatish.
- Cluster boshlash (Docker driver).
- Pod yaratish.
- Deployment va Service.
- Ingress va Volume.
- Dashboard GUI.
</Callout>

## 1. Talablar

- 2 CPU+, 2 GB RAM+, 20 GB disk
- Docker yoki VirtualBox o'rnatilgan
- Ubuntu 20.04+

## 2. Docker yoki KVM o'rnatish

Docker driver tavsiya etiladi:

```bash
# Docker (oldingi darsdan)
sudo apt install -y docker.io
sudo usermod -aG docker $USER
newgrp docker
```

Yoki KVM:

```bash
sudo apt install -y qemu-kvm libvirt-daemon-system libvirt-clients
sudo usermod -aG libvirt $USER
newgrp libvirt
```

## 3. Minikube o'rnatish

```bash
curl -LO https://storage.googleapis.com/minikube/releases/latest/minikube-linux-amd64
sudo install minikube-linux-amd64 /usr/local/bin/minikube
rm minikube-linux-amd64

minikube version
# minikube version: v1.34.x
```

## 4. kubectl o'rnatish

```bash
curl -LO "https://dl.k8s.io/release/$(curl -L -s https://dl.k8s.io/release/stable.txt)/bin/linux/amd64/kubectl"
sudo install kubectl /usr/local/bin/kubectl
rm kubectl

kubectl version --client
# Client Version: v1.31.x
```

Yoki snap:

```bash
sudo snap install kubectl --classic
```

## 5. Cluster boshlash

```bash
# Docker driver
minikube start --driver=docker

# Resurs ko'paytirib
minikube start --driver=docker --cpus=4 --memory=8g --disk-size=40g

# Yoki KVM
minikube start --driver=kvm2

# Versiya
minikube start --kubernetes-version=v1.30.0
```

Boshlash 1-2 daqiqa.

```bash
minikube status
# host: Running
# kubelet: Running
# apiserver: Running

kubectl get nodes
# NAME       STATUS   ROLES           AGE   VERSION
# minikube   Ready    control-plane   1m    v1.30.x
```

## 6. Pod yaratish

```bash
# Imperative
kubectl run nginx --image=nginx:alpine
kubectl get pods
kubectl describe pod nginx
kubectl logs nginx
kubectl delete pod nginx
```

YAML:

`pod.yaml`:

```yaml
apiVersion: v1
kind: Pod
metadata:
  name: nginx
  labels:
    app: web
spec:
  containers:
  - name: nginx
    image: nginx:alpine
    ports:
    - containerPort: 80
```

```bash
kubectl apply -f pod.yaml
kubectl get pods
kubectl delete -f pod.yaml
```

## 7. Deployment

`deployment.yaml`:

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: nginx-deployment
spec:
  replicas: 3
  selector:
    matchLabels:
      app: nginx
  template:
    metadata:
      labels:
        app: nginx
    spec:
      containers:
      - name: nginx
        image: nginx:alpine
        ports:
        - containerPort: 80
        resources:
          limits:
            cpu: "500m"
            memory: "256Mi"
          requests:
            cpu: "100m"
            memory: "64Mi"
```

```bash
kubectl apply -f deployment.yaml
kubectl get deployment
kubectl get pods
# nginx-deployment-xxx (3 pod)

# Scale
kubectl scale deployment nginx-deployment --replicas=5

# Rolling update
kubectl set image deployment/nginx-deployment nginx=nginx:1.27-alpine
kubectl rollout status deployment/nginx-deployment

# Rollback
kubectl rollout undo deployment/nginx-deployment
```

## 8. Service

Pod'larga tashqaridan ulanish:

`service.yaml`:

```yaml
apiVersion: v1
kind: Service
metadata:
  name: nginx-svc
spec:
  selector:
    app: nginx
  ports:
  - port: 80
    targetPort: 80
  type: NodePort     # yoki ClusterIP, LoadBalancer
```

```bash
kubectl apply -f service.yaml
kubectl get svc
# nginx-svc   NodePort   10.x.x.x   <none>   80:30000/TCP

# URL
minikube service nginx-svc --url
# http://192.168.49.2:30000

# Brauzer
curl $(minikube service nginx-svc --url)
```

## 9. ConfigMap va Secret

```yaml
apiVersion: v1
kind: ConfigMap
metadata:
  name: app-config
data:
  ENVIRONMENT: production
  LOG_LEVEL: info
---
apiVersion: v1
kind: Secret
metadata:
  name: app-secret
type: Opaque
stringData:
  DB_PASSWORD: "MySecret!"
```

Pod ichidan ishlatish:

```yaml
spec:
  containers:
  - name: app
    image: myapp
    envFrom:
    - configMapRef:
        name: app-config
    - secretRef:
        name: app-secret
```

## 10. Persistent Volume

`pvc.yaml`:

```yaml
apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: data-pvc
spec:
  accessModes:
  - ReadWriteOnce
  resources:
    requests:
      storage: 1Gi
```

Pod'da:

```yaml
spec:
  containers:
  - name: app
    image: myapp
    volumeMounts:
    - name: data
      mountPath: /data
  volumes:
  - name: data
    persistentVolumeClaim:
      claimName: data-pvc
```

## 11. Ingress

```bash
# Ingress controller (nginx)
minikube addons enable ingress
```

`ingress.yaml`:

```yaml
apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  name: web-ingress
  annotations:
    nginx.ingress.kubernetes.io/rewrite-target: /
spec:
  rules:
  - host: myapp.local
    http:
      paths:
      - path: /
        pathType: Prefix
        backend:
          service:
            name: nginx-svc
            port:
              number: 80
```

```bash
kubectl apply -f ingress.yaml

# /etc/hosts ga
echo "$(minikube ip) myapp.local" | sudo tee -a /etc/hosts

curl http://myapp.local
```

## 16. Misol — to'liq web app

```yaml
# app-stack.yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: api
spec:
  replicas: 2
  selector:
    matchLabels:
      app: api
  template:
    metadata:
      labels:
        app: api
    spec:
      containers:
      - name: api
        image: hashicorp/http-echo
        args: ["-text=Hello, Kubernetes!"]
        ports:
        - containerPort: 5678
---
apiVersion: v1
kind: Service
metadata:
  name: api-svc
spec:
  selector:
    app: api
  ports:
  - port: 80
    targetPort: 5678
---
apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  name: api-ingress
spec:
  rules:
  - host: api.local
    http:
      paths:
      - path: /
        pathType: Prefix
        backend:
          service:
            name: api-svc
            port:
              number: 80
```

```bash
kubectl apply -f app-stack.yaml
echo "$(minikube ip) api.local" | sudo tee -a /etc/hosts
curl http://api.local
```

## 17. Cleanup

```bash
# Pod'larni o'chirish
kubectl delete -f app-stack.yaml

# Cluster to'xtatish
minikube stop

# Cluster o'chirish
minikube delete

# Hammasi (profillar)
minikube delete --all
```

## 18. Eng tez-tez uchraydigan xatolar

- **Driver tanlanmasdan** — `minikube start` qaysi'sini ishlatishni bilmaydi.
- **Docker `sudo`'siz** — `newgrp docker` qiling.
- **Resurs kam** — minimum 2 CPU, 2 GB RAM.
- **`/etc/hosts` qo'shilmagan** — Ingress'da `myapp.local` ishlamaydi.
- **Image pull `imagePullBackOff`** — image nomi noto'g'ri.

## 19. Eng yaxshi amaliyot

- **Docker driver** — eng yengil.
- **YAML manifest'lar** — Git'da.
- **Resource limit** — har container.
- **Namespace** — `dev`, `prod` alohida.
- **`minikube tunnel`** — LoadBalancer service'lar uchun.

## 20. Mashqlar

1. **O'rnatish:** Minikube va kubectl.
2. **Cluster:** `minikube start`.
3. **Deployment:** 3 ta replica nginx.
4. **Service:** NodePort, URL'ni oching.
5. **Ingress:** Custom hostname bilan.

## 21. Bilim sinovi

**Savol 1.** Minikube nima beradi?

- a) Production K8s
- b) Lokal bitta-tugun K8s cluster (o'rganish)
- c) Cloud K8s
- d) Hech narsa

<Callout type="success" title="Javob">
**(b)** Local dev/test/o'rganish uchun.[¹](https://minikube.sigs.k8s.io/docs/)
</Callout>

**Savol 2.** Deployment nima qiladi?

- a) Bitta pod
- b) Ko'p replica + rolling update
- c) Service
- d) Volume

<Callout type="success" title="Javob">
**(b)** Replicas, rolling update, rollback boshqaradi.
</Callout>

**Savol 3.** Service type `NodePort`:

- a) Internal faqat
- b) Har node'da port ochiladi (tashqaridan)
- c) LoadBalancer
- d) Hech narsa

<Callout type="success" title="Javob">
**(b)** 30000-32767 port range — minikube IP orqali tashqaridan.
</Callout>

**Savol 4.** Ingress nima uchun?

- a) Volume
- b) HTTP/HTTPS traffic — host va path'lar bilan routing
- c) Network policy
- d) ConfigMap

<Callout type="success" title="Javob">
**(b)** L7 router — `nginx-ingress` controller bilan.
</Callout>

**Savol 5.** Cluster o'chirish:

- a) `minikube stop`
- b) `minikube delete`
- c) `kubectl delete cluster`
- d) Hech narsa

<Callout type="success" title="Javob">
**(b)** `delete` — to'liq o'chiradi. `stop` — to'xtatadi (qayta start mumkin).
</Callout>
