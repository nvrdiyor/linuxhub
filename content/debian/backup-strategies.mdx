**Backup** — production server'ning eng muhim funksiyasi. Disk buzilsa, ransomware, xato — backup'siz tiklash imkonsiz. Debian'da `rsync`, `borgbackup`, `restic` — eng yaxshi vositalar.[¹](https://www.borgbackup.org/)

<Callout type="info" title="Bu darsda nimani o'rganasiz">
- 3-2-1 backup qoidasi.
- `rsync` — eng oson.
- `borgbackup` — deduplicated.
- `restic` — modern + cloud.
- Cron va systemd timer.
- Restore test.
</Callout>

## 1. 3-2-1 qoida

- **3** ta nusxa: production + 2 backup.
- **2** ta turli media: local disk + tape/external.
- **1** ta off-site: boshqa joyda (cloud, boshqa shahar).

## 2. Nimani backup qilish?

Server'da odatda:

- `/etc/` — konfiguratsiya.
- `/home/` — foydalanuvchi fayllari.
- `/var/www/` — web fayllar.
- `/var/lib/postgresql/` (yoki SQL dump).
- `/var/lib/docker/volumes/` (yoki volume backup).
- Aniq dastur data (`/srv/`, `/opt/myapp/`).

**Yo'q:**

- `/dev/`, `/proc/`, `/sys/`, `/tmp/`, `/run/`.
- `/var/cache/`, `/var/log/` (debug'da kerak bo'lsa — alohida).
- `/lost+found/`.

## 3. rsync — eng oson

```bash
# Lokal
rsync -aAXv /home/ /mnt/backup/home/

# Remote
rsync -aAXv /home/ user@backup-server:/srv/backups/home/

# Incremental (faqat o'zgargan'lar)
rsync -aAXv --delete /home/ /mnt/backup/home/

# Excludes
rsync -aAXv \
    --exclude='/dev/*' \
    --exclude='/proc/*' \
    --exclude='/sys/*' \
    --exclude='/tmp/*' \
    --exclude='/run/*' \
    --exclude='/mnt/*' \
    --exclude='/media/*' \
    --exclude='/var/cache/*' \
    --exclude='/lost+found' \
    / /mnt/backup/
```

Flag'lar:

- `-a` — archive (rlptgoD)
- `-A` — ACL preservation
- `-X` — extended attributes
- `-v` — verbose
- `--delete` — destination'da source'da yo'q fayllarni o'chirish
- `--progress` — progress bar

## 4. rsync — incremental snapshot

```bash
#!/bin/bash
DATE=$(date +%Y%m%d-%H%M%S)
DEST=/mnt/backup
SRC=/home/

# Hardlink incremental
rsync -aAX --delete \
    --link-dest=$DEST/latest \
    $SRC $DEST/$DATE/

# Latest symlink
rm -f $DEST/latest
ln -s $DEST/$DATE $DEST/latest
```

Har snapshot — faqat o'zgargan'lar yangi joyda, qolgani hardlink (disk tejash).

## 5. borgbackup — deduplicated

Eng yaxshi backup tool:

- **Deduplication** — bir xil blok'lar bir marta.
- **Encryption** — repository encrypted.
- **Compression** — lz4, zstd.
- **Incremental** — faqat o'zgargan'lar.

```bash
sudo apt install -y borgbackup

# Repository yaratish
borg init --encryption=repokey /mnt/backup/borg

# Birinchi backup
borg create \
    --stats --progress \
    --compression zstd,3 \
    /mnt/backup/borg::myserver-$(date +%Y%m%d) \
    /etc /home /var/www /srv

# Ro'yxat
borg list /mnt/backup/borg

# Prune (eski'larni)
borg prune \
    --keep-daily=7 \
    --keep-weekly=4 \
    --keep-monthly=6 \
    /mnt/backup/borg
```

## 6. borg restore

```bash
# Ko'rish
borg list /mnt/backup/borg::myserver-20260526

# To'liq restore
borg extract /mnt/backup/borg::myserver-20260526

# Aniq fayl
borg extract /mnt/backup/borg::myserver-20260526 etc/nginx/nginx.conf

# Mount
mkdir /tmp/mnt
borg mount /mnt/backup/borg::myserver-20260526 /tmp/mnt
ls /tmp/mnt
borg umount /tmp/mnt
```

## 7. borg remote

```bash
# SSH bilan
ssh-keygen -t ed25519
ssh-copy-id backup@backup-server

# Repository yaratish
borg init --encryption=repokey backup@backup-server:/srv/borg

# Backup
borg create \
    --stats \
    backup@backup-server:/srv/borg::myserver-$(date +%Y%m%d) \
    /etc /home

# `borg serve` server'da
```

## 8. restic — modern alternatif

Cloud storage qo'llab-quvvatlaydi (S3, B2, GCS, Azure):

```bash
sudo apt install -y restic

# Local repo
restic init --repo /mnt/backup/restic
# Enter password

# S3
export AWS_ACCESS_KEY_ID=...
export AWS_SECRET_ACCESS_KEY=...
restic init --repo s3:s3.amazonaws.com/mybucket

# Backblaze B2
export B2_ACCOUNT_ID=...
export B2_ACCOUNT_KEY=...
restic init --repo b2:mybucket

# Backup
restic -r /mnt/backup/restic backup /etc /home

# List
restic -r /mnt/backup/restic snapshots

# Restore
restic -r /mnt/backup/restic restore latest --target /tmp/restore

# Forget va prune
restic -r /mnt/backup/restic forget \
    --keep-daily=7 --keep-weekly=4 --keep-monthly=6 --prune
```

## 9. Database backup

PostgreSQL:

```bash
sudo -u postgres pg_dumpall > /tmp/all.sql
sudo -u postgres pg_dump mydb > /tmp/mydb.sql

# Compressed
sudo -u postgres pg_dump -Fc mydb > /tmp/mydb.dump
```

MySQL/MariaDB:

```bash
sudo mysqldump --all-databases --single-transaction > /tmp/all.sql
```

Cron'da har vaqt avval DB dump qilib, keyin backup.

## 10. Avtomatik script

`/usr/local/bin/backup.sh`:

```bash
#!/bin/bash
set -euo pipefail

LOG=/var/log/backup.log
exec > >(tee -a $LOG) 2>&1

DATE=$(date +%Y%m%d-%H%M%S)
echo "=== Backup started: $DATE ==="

# 1. Database
echo "[*] PostgreSQL dump"
sudo -u postgres pg_dumpall > /tmp/postgres-$DATE.sql

# 2. Borg
echo "[*] Borg backup"
export BORG_PASSPHRASE="MySecret"
borg create --stats --progress \
    --exclude='/var/cache/*' --exclude='/var/log/*' \
    /mnt/backup/borg::server-$DATE \
    /etc /home /var/www /srv /tmp/postgres-$DATE.sql

# 3. Cleanup
rm -f /tmp/postgres-$DATE.sql

# 4. Prune
echo "[*] Borg prune"
borg prune --list --keep-daily=7 --keep-weekly=4 --keep-monthly=6 /mnt/backup/borg

# 5. Check
echo "[*] Borg check"
borg check /mnt/backup/borg

echo "=== Backup completed: $(date) ==="
```

```bash
sudo chmod +x /usr/local/bin/backup.sh
```

## 11. systemd timer

`/etc/systemd/system/backup.service`:

```ini
[Unit]
Description=Daily backup

[Service]
Type=oneshot
ExecStart=/usr/local/bin/backup.sh
```

`/etc/systemd/system/backup.timer`:

```ini
[Unit]
Description=Daily backup timer

[Timer]
OnCalendar=daily
Persistent=true
RandomizedDelaySec=30min

[Install]
WantedBy=timers.target
```

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now backup.timer
sudo systemctl list-timers backup
```

## 12. Restore test

**Backup test qilinmagan — backup yo'q.** Har oyda restore test:

```bash
# Lab muhitida
mkdir /tmp/restore-test
borg extract --strip-components 2 /mnt/backup/borg::server-LATEST etc/nginx/nginx.conf

# Yoki to'liq mount
borg mount /mnt/backup/borg::server-LATEST /mnt/restore
ls /mnt/restore/etc/
borg umount /mnt/restore
```

## 15. Eng tez-tez uchraydigan xatolar

- **Backup test qilinmagan** — restore'da bilasiz buzilganini.
- **`rsync --delete`'siz** — destination o'sib boradi.
- **Borg passphrase yo'qolgan** — repository decrypt qilinmaydi.
- **Cron log'ga yo'naltirilmagan** — debug'da hech narsa.
- **Disk to'lib qolgan** — prune ishlatilmagan.

## 16. Eng yaxshi amaliyot

- **3-2-1 qoidasi** — har vaqt.
- **Borg yoki Restic** — deduplicated + encrypted.
- **Off-site** — boshqa joyda nusxa.
- **Restore test har oyda** — backup ishlamasligi mumkin.
- **Monitoring** — Slack/email failure'da xabar.
