Debian boshqa distributivlardan farqli ravishda **ko'p shoxchali** ishlaydi. Har vaqt **uchta asosiy shoxcha** mavjud: **Stable**, **Testing** va **Unstable (Sid)**. Paketlar Sid'dan boshlanib, Testing orqali Stable'ga yetib boradi.[²](https://www.debian.org/doc/manuals/debian-faq/ftparchives)

<Callout type="info" title="Bu darsda nimani o'rganasiz">
- Stable, Testing va Sid shoxchalarining roli.
- Paketning sayohati: Sid → Testing → Stable.
- Qaysi shoxcha qaysi foydalanuvchi turiga mos.
- `Experimental` shoxchasi qisqacha.
</Callout>

## 1. Uchta shoxcha

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│   Sid (Unstable)  ──▶  Testing  ──▶  Stable                │
│   doimo o'zgaradi      sinov           barqaror             │
│   ko'p bug             oraliq          yamoq + xavfsizlik   │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### Stable (barqaror)

Bu — **Debian'ning rasmiy nashri**. Hozir `bookworm` (Debian 12).

- Faqat **xavfsizlik yamoqlari** va kritik bug-fix'lar oladi.
- Paketlar o'zgarishlardan himoyalangan — versiya raqami doimiy qoladi.
- Server, ishlab chiqarish muhitlari uchun ideal.

### Testing

- Stable'ga **tayyorgarlik bosqichidagi paketlar** to'plami.
- Hozir Stable bo'lib chiqayotgan reliz `trixie` deb ataladi.
- Paketlar Sid'da kamida 10 kun davomida jiddiy bug'larsiz qolsa, avtomatik ravishda Testing'ga ko'chiriladi.[³](https://www.debian.org/devel/testing)
- Yangi paketlar uchun yetarli tezlikda yangilanadi, lekin u Stable'dan ko'ra barqarorroq.

### Unstable (Sid)

- Debian rivojlanish shoxchasi.
- Ko'p hollarda yangi paketlar avval shu yerga keladi.
- "Sid" doimiy nom — u "Stable nomiga aylanmaydi" (bu Toy Story'dagi yomon bolaga ishora).
- **Doimo bug bo'lishi mumkin.**

### Experimental

To'rtinchi shoxcha — `experimental`. Bu rasmiy distributiv emas, balki Sid'dagi paketlar ham juda erta bo'lgan paketlar to'plami (masalan, asosiy kutubxonaning yangi versiyasi sinov uchun). Foydalanuvchilar uni qo'lda yoqishi kerak.

## 2. Paketning sayohati

```
Yangi paket yoki versiya
        ↓
  Experimental (ixtiyoriy)
        ↓
       Sid
        ↓ (10+ kun, jiddiy bug yo'q)
     Testing
        ↓ (reliz freeze va sinov)
     Stable
        ↓ (5 yildan keyin)
   eski-stable
```

Bu jarayon paketning **xavfsizroq Stable'ga yetib borishini ta'minlaydi**.

## 3. Qaysi shoxcha qaysi foydalanuvchi uchun?

| Shoxcha | Kim uchun | Misol vaziyat |
|---|---|---|
| **Stable** | Server, kompyuter ishchi joyi | Veb-server, mijozlarga xizmat |
| **Stable + backports** | Stable bilan barqarorlik, lekin ba'zi paketlar yangiroq | Dasturchi noutbuki |
| **Testing** | Yangi dasturlarni xohlovchi tajribali foydalanuvchi | "Ish stoli" foydalanuvchi |
| **Sid** | Debian dasturchilari, kuchli foydalanuvchilar | Paket sinovi, rivojlanish |
| **Experimental** | Faqat paketni sinaganlar | Yangi GCC versiyasi sinov |

## 4. Shoxchani o'zgartirish

Stable'dan Testing'ga o'tish — kelajakdagi Stable relizga yo'lni ochish demakdir. `/etc/apt/sources.list` da kodli nomni o'zgartiring:

```
# Stable (bookworm) o'rniga Testing (trixie)
deb http://deb.debian.org/debian trixie main contrib non-free non-free-firmware
```

So'ng:

```bash
sudo apt update
sudo apt full-upgrade
```

<Callout type="warning">
**Stable'dan Testing/Sid'ga o'tish bir tomonlama amaliyot.** Orqaga qaytish murakkab va ko'pincha tizimni qayta o'rnatishga olib keladi. Ehtiyot bo'ling va majburiy ravishda backup oling.
</Callout>

## 5. Kodli nomlar va `stable` aliyaslari

`sources.list` da ikki yondashuv:

- **Kodli nom** (`bookworm`, `trixie`) — relizni qattiq biriktiradi. Yangi reliz chiqqanda, sizning tizimingiz **avtomatik yangilanmaydi**.
- **Aliyaslar** (`stable`, `testing`, `unstable`) — har vaqt joriy reliz. Yangi reliz chiqqanda, sizning tizimingiz **avtomatik o'tadi**.

Tavsiya: **kodli nom** ishlatish — bu kutilmagan reliz yangilanishidan saqlaydi.

```
# Yaxshi (kodli nom)
deb http://deb.debian.org/debian bookworm main

# Ehtiyot bo'ling (aliyas)
deb http://deb.debian.org/debian stable main
```

## 6. Joriy holatingizni bilish

```bash
# Reliz va kodli nom
cat /etc/debian_version
lsb_release -a

# Qaysi shoxchalar yoqilgan
grep -h "^deb " /etc/apt/sources.list /etc/apt/sources.list.d/*.list
```
