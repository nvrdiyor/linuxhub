**Debian** — bu eng eski va eng nufuzli Linux distributivlaridan biri, butunlay ko'ngillilardan tashkil topgan global hamjamiyat tomonidan ishlab chiqiladi.[¹](https://www.debian.org/intro/about) Loyiha 1993-yilda Ian Murdock tomonidan yaratilgan va shundan beri "erkin dasturlar" tamoyiliga sodiq qolib kelmoqda.

<Callout type="info" title="Bu darsda nimani o'rganasiz">
- Debian kim tomonidan va qachon yaratilganligi.
- Loyihaning tashkiliy tuzilishi (hech qanday kompaniya emas).
- Debian'ning asosiy farqlovchi xususiyatlari.
- Debian asosidagi mashhur distributivlar.
</Callout>

## 1. Debian — nima va kim tomonidan?

Debian — bu **hamjamiyat loyihasi**. Hech qanday kompaniya uni "egasi" emas:[¹](https://www.debian.org/intro/about)

- 1000+ ko'ngilli **Debian Developer** (DD) maqomidagi a'zolar tomonidan rivojlantiriladi.
- Saylanadigan **Debian Project Leader** har yili qayta tanlanadi.
- Loyiha xarajatlari (serverlar, tadbirlar) ham faqat xayriya orqali yopiladi — "Software in the Public Interest" tashkiloti orqali.

So'zning kelib chiqishi: "Debian" = **Deb**ra (Ian Murdock'ning xotini) + **Ian** (uning ismi).[³](https://www.debian.org/doc/manuals/project-history/)

## 2. Falsafasi: erkin dasturlar

Debian "100% erkin dasturlar" tamoyiliga sodiq.[²](https://www.debian.org/intro/why_debian) Bu shuni anglatadi:

- Asosiy distributivga faqat **Debian Free Software Guidelines (DFSG)** ga mos keluvchi paketlar kiradi.
- Maxsus drayverlar va prashivkalar (non-free firmware) alohida `non-free-firmware` repozitoriysida.
- Foydalanuvchi har doim ko'rishi kerak: qaysi paket erkin, qaysi qaysi shartlar bilan.

Bu Ubuntu va boshqa "amaliyotchi" distributivlardan ajralib turuvchi xususiyat — Ubuntu drayverlarni boshlanishidayoq taklif qiladi, Debian esa avval foydalanuvchidan tushuncha so'raydi.

## 3. Debian'ning farqlovchi xususiyatlari

| Xususiyat | Tafsilot |
|---|---|
| **Barqarorlik** | Stable reliz — minglab paketlar sinovdan o'tgandan keyingina chiqariladi. |
| **Erkinlik** | DFSG — qattiq mezon. |
| **Universallik** | Desktop, server, embedded, mainframe — barchasi uchun bitta distributiv. |
| **Uzoq umrlik** | Har reliz **5 yil** yordam oladi (3 yil standart + 2 yil LTS). |
| **Mustaqillik** | Hech qanday kompaniya boshqarmaydi. |

## 4. Debian asosidagi distributivlar

Debian Linux dunyosining "ildizi" — undan ko'plab distributivlar paydo bo'lgan:

```
Debian
├── Ubuntu (Canonical)
│   ├── Linux Mint
│   ├── Elementary OS
│   ├── Pop!_OS
│   └── Kubuntu, Xubuntu, Lubuntu (flavor'lar)
├── Kali Linux (Offensive Security)
├── Parrot OS
├── MX Linux
├── Tails
└── Raspberry Pi OS (eski Raspbian)
```

Bu distributivlarning hammasi `apt`, `dpkg`, `.deb` paket formatini Debian'dan oladi.

## 5. Reliz nomlari

Har bir Debian relizi **Toy Story** filmidagi qahramon nomi bilan ataladi:[³](https://www.debian.org/doc/manuals/project-history/)

| Versiya | Kodli nom | Sana |
|---|---|---|
| Debian 10 | **Buster** | 2019 |
| Debian 11 | **Bullseye** | 2021 |
| Debian 12 | **Bookworm** | 2023 |
| Debian 13 | **Trixie** | rejalashtirilmoqda |
| `unstable` | **Sid** (hech qachon o'zgarmaydi) | doimiy |

`Sid` — bu Toy Story'dagi "yomon" bola; Debian rivojlanish shoxchasi ham har vaqt buzilishi mumkin bo'lgani uchun shu nom berilgan.

## 6. Qanday foydalanish

Debian quyidagi vazifalar uchun mukammal:

- **Server** — barqarorligi tufayli.
- **Tajriba** — sinovdan o'tgan paketlar kerak bo'lganda.
- **Eski apparat** — yengilroq dasturlash va kichikroq talablar.
- **O'rganish** — Linuxni chuqurroq tushunish uchun.

## 7. Amaliy misol

Debian o'rnatilgan tizimda:

```bash
# Reliz va kodli nom
cat /etc/debian_version
# Misol: 12.7

lsb_release -a
```

```
Distributor ID: Debian
Description:    Debian GNU/Linux 12 (bookworm)
Release:        12
Codename:       bookworm
```
